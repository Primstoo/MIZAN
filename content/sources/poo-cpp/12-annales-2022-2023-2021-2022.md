## Examen 2022-2023 · Client, Article, LigneCommande, Commande (1 h 30)

**Énoncé (résumé).** Un client a un nom, un prénom (string) et un numéro (int). Q1–Q7 : classe `Client`, accesseurs `getNom/getPrenom/getNumero`, mutateurs `setNom/setPrenom/setNumero`, constructeur, constructeur de recopie, `Affiche()` utilisable sur des objets constants, `operator=`. Q8–Q12 : classe `Article` (titre string, prix double) avec accesseurs, mutateurs, constructeur, `Affiche()`. Q13–Q17 : classe `LingeCommande` (sic) avec `myArticle` (Article) et `quantite` (long), accesseurs, mutateurs, constructeur, `Affiche()`. Q18–Q22 : classe `Commande` composée de lignes de commande, d'un client, d'une référence et d'une date (string) : constructeur avec valeurs par défaut, `AjouterLigneCommande(...)`, `EnleverLigneCommande(...)`, `print()`.

> [!attention] Le sujet écrit « LingeCommande » : c'est une coquille pour **LigneCommande**. Le corrigé garde `myArticle` comme **pointeur** : l'article existe en dehors de la ligne (catalogue), la ligne ne doit donc pas le détruire.

```etapes Les points qui rapportent
Q6 const :: `void Affiche() const` : sinon `c1.Affiche()` sur un `const Client` ne compile pas.
Q7 affectation :: test `this != &c`, copie des champs, `return *this`.
Q19 valeurs par défaut :: dans la **déclaration** du constructeur : `Commande(Client c = Client(), string ref = "", ...)`.
Q20/Q21 :: tableau de pointeurs + compteur ; enlever = chercher puis **décaler** les suivants.
Destructeur :: `delete[]` du tableau de pointeurs, pas des lignes (elles ne sont pas à la commande).
```

```cpp
#include <iostream>
#include <string>
using namespace std;

class Client {
    string nom, prenom;
    int numero;
public:
    // Q4 : constructeur (valeurs par défaut)
    Client(string n = "", string p = "", int num = 0) : nom(n), prenom(p), numero(num) {}
    // Q5 : constructeur de recopie
    Client(const Client& c) : nom(c.nom), prenom(c.prenom), numero(c.numero) {}
    // Q2 : lecture
    string getNom() const { return nom; }
    string getPrenom() const { return prenom; }
    int getNumero() const { return numero; }
    // Q3 : modification
    void setNom(string n) { nom = n; }
    void setPrenom(string p) { prenom = p; }
    void setNumero(int num) { numero = num; }
    // Q6 : const pour accepter les objets constants
    void Affiche() const { cout << "Client " << numero << " : " << prenom << " " << nom << endl; }
    // Q7 : affectation
    Client& operator=(const Client& c) {
        if (this != &c) { nom = c.nom; prenom = c.prenom; numero = c.numero; }
        return *this;
    }
};

class Article {
    string titre;
    double prix;
public:
    Article(string t = "", double p = 0) : titre(t), prix(p) {}     // Q11
    string getTitre() const { return titre; }                       // Q9
    double getPrix() const { return prix; }
    void setTitre(string t) { titre = t; }                          // Q10
    void setPrix(double p) { prix = p; }
    void Affiche() const { cout << titre << " (" << prix << " DH)"; } // Q12
};

class LigneCommande {
    Article* myArticle;   // l'article n'appartient pas à la ligne : pas de delete
    long quantite;
public:
    LigneCommande(Article* a = nullptr, long q = 0) : myArticle(a), quantite(q) {} // Q16
    Article* getMyArticle() const { return myArticle; }  // Q14
    long getQuantite() const { return quantite; }
    void setMyArticle(Article* a) { myArticle = a; }     // Q15
    void setQuantite(long q) { quantite = q; }
    void Affiche() const {                                // Q17
        myArticle->Affiche();
        cout << " x " << quantite << " = " << myArticle->getPrix() * quantite << " DH" << endl;
    }
};

class Commande {
    Client client;
    LigneCommande** lignes;   // tableau de pointeurs vers les lignes
    int nbLignes, capacite;
    string reference, date;
public:
    // Q19 : constructeur avec valeurs par défaut
    Commande(Client c = Client(), string ref = "", string d = "", int cap = 10)
        : client(c), nbLignes(0), capacite(cap), reference(ref), date(d) {
        lignes = new LigneCommande*[capacite];
    }
    ~Commande() { delete[] lignes; }   // on libère le tableau, pas les lignes
    Commande(const Commande&) = delete; // évite la double libération
    Commande& operator=(const Commande&) = delete;
    // Q20
    void AjouterLigneCommande(LigneCommande* l) {
        if (nbLignes < capacite) lignes[nbLignes++] = l;
        else cout << "Commande pleine" << endl;
    }
    // Q21 : on décale les lignes suivantes
    void EnleverLigneCommande(LigneCommande* l) {
        for (int i = 0; i < nbLignes; i++)
            if (lignes[i] == l) {
                for (int j = i; j < nbLignes - 1; j++) lignes[j] = lignes[j + 1];
                nbLignes--;
                return;
            }
        cout << "Ligne introuvable" << endl;
    }
    // Q22
    void print() const {
        cout << "Commande " << reference << " du " << date << endl;
        client.Affiche();
        double total = 0;
        for (int i = 0; i < nbLignes; i++) {
            cout << "  - "; lignes[i]->Affiche();
            total += lignes[i]->getQuantite() * lignes[i]->getMyArticle()->getPrix();
        }
        cout << "Total : " << total << " DH" << endl;
    }
};

int main() {
    const Client c1("Alaoui", "Sara", 7);
    c1.Affiche();                      // objet constant : OK grâce à const
    Client c2 = c1;                    // recopie
    c2.setPrenom("Omar");
    c2.Affiche();
    Article* a1 = new Article("Python for Data Science", 200);
    Article* a2 = new Article("Cryptographie", 300);
    LigneCommande* l1 = new LigneCommande(a1, 2);
    LigneCommande* l2 = new LigneCommande(a2, 1);
    Commande com(c2, "com1", "12-6-2024");
    com.AjouterLigneCommande(l1);
    com.AjouterLigneCommande(l2);
    com.print();
    com.EnleverLigneCommande(l1);
    com.print();
    delete l1; delete l2; delete a1; delete a2;
    return 0;
}
```

```sortie

Client 7 : Omar Alaoui
Commande com1 du 12-6-2024
Client 7 : Omar Alaoui
  - Python for Data Science (200 DH) x 2 = 400 DH
  - Cryptographie (300 DH) x 1 = 300 DH
Total : 700 DH
Commande com1 du 12-6-2024
Client 7 : Omar Alaoui
  - Cryptographie (300 DH) x 1 = 300 DH
Total : 300 DH
```

> [!retenir] Dès qu'une classe fait `new` dans son constructeur, il faut trancher sur la recopie : soit tu écris recopie + `operator=` en profondeur, soit tu les interdis (`= delete`). Sinon deux objets libèrent le même tableau.

```exercice Questions de l'examen 2022-2023
? Q6 : pourquoi `Affiche()` doit-elle être déclarée `const` ?
= Parce qu'on ne peut appeler sur un objet constant (`const Client c1(...)`) que des méthodes `const`. Le mot-clé promet que la méthode ne modifie pas l'objet.

? Q7 : écris l'en-tête et le squelette de `operator=` pour `Client`.
= `Client& operator=(const Client& c) { if (this != &c) { nom = c.nom; prenom = c.prenom; numero = c.numero; } return *this; }` : le test évite l'auto-affectation, le retour par référence permet `a = b = c`.

? Q21 : comment enlever une ligne d'un tableau de pointeurs sans laisser de trou ?
= On cherche l'indice i de la ligne, on décale `lignes[j] = lignes[j+1]` pour j de i à nbLignes − 2, puis `nbLignes--`. On ne fait pas `delete` : la ligne appartient à l'appelant.

? Que se passe-t-il si `Commande` a un `new` dans son constructeur, un `delete[]` dans son destructeur, et qu'on copie une commande sans constructeur de recopie ?
= La copie par défaut recopie le **pointeur** : les deux commandes partagent le même tableau, et il est libéré deux fois à la destruction (comportement indéfini, souvent un plantage).
```

## Examen 2021-2022 · Individu, Etudiant, Enseignant, Departement (2 h)

**Énoncé (résumé).** Q1–Q7 : classe `Individu` (nom, prenom, mail : string), `ObtenirNom/Prenom/Mail`, `ModifierNom/Prenom/Mail`, constructeur, recopie, `Affiche()` pour objets constants, `operator=`. Q8–Q10 : `Etudiant` hérite publiquement d'`Individu` avec `Promo` (int) et `groupe` (string), redéfinit `Affiche()`, constructeur. Q11–Q13 : `Enseignant` avec `matiere` (string), même chose. Q14–Q19 : `Departement` composé de `nbEtudiants` étudiants et `nbEnseignants` enseignants : constructeur avec valeurs par défaut, `AjouterEtudiant()`, `AjouterEnseignant()`, `EnleverEtudiant()`, `EffectifEtudiants()`.

```etapes Les points qui rapportent
Attributs protected :: pour que `Etudiant::Affiche` puisse les lire (sinon passer par `ObtenirNom()`).
Constructeur dérivé :: liste d'initialisation qui appelle `Individu(n, p, m)` en premier.
Redéfinition :: même signature, `virtual` dans la base pour qu'un `Individu*` appelle la bonne version.
Affiche de la base :: réutilisée avec `Individu::Affiche();`.
Departement :: deux tableaux de pointeurs + deux compteurs ; `EffectifEtudiants()` renvoie le compteur.
```

```cpp
#include <iostream>
#include <string>
using namespace std;

class Individu {
protected:
    string nom, prenom, mail;
public:
    Individu(string n = "", string p = "", string m = "") : nom(n), prenom(p), mail(m) {} // Q4
    Individu(const Individu& i) : nom(i.nom), prenom(i.prenom), mail(i.mail) {}          // Q5
    virtual ~Individu() {}
    string ObtenirNom() const { return nom; }          // Q2
    string ObtenirPrenom() const { return prenom; }
    string ObtenirMail() const { return mail; }
    void ModifierNom(string n) { nom = n; }            // Q3
    void ModifierPrenom(string p) { prenom = p; }
    void ModifierMail(string m) { mail = m; }
    virtual void Affiche() const {                     // Q6 (const + virtual)
        cout << prenom << " " << nom << " <" << mail << ">";
    }
    Individu& operator=(const Individu& i) {           // Q7
        if (this != &i) { nom = i.nom; prenom = i.prenom; mail = i.mail; }
        return *this;
    }
};

class Etudiant : public Individu {                     // Q8
    int Promo;
    string groupe;
public:
    Etudiant(string n = "", string p = "", string m = "", int pr = 0, string g = "")
        : Individu(n, p, m), Promo(pr), groupe(g) {}   // Q10
    void Affiche() const override {                    // Q9
        cout << "Etudiant : "; Individu::Affiche();
        cout << ", promo " << Promo << ", groupe " << groupe << endl;
    }
};

class Enseignant : public Individu {                   // Q11
    string matiere;
public:
    Enseignant(string n = "", string p = "", string m = "", string mat = "")
        : Individu(n, p, m), matiere(mat) {}           // Q13
    void Affiche() const override {                    // Q12
        cout << "Enseignant : "; Individu::Affiche();
        cout << ", matiere " << matiere << endl;
    }
};

class Departement {                                    // Q14
    Etudiant** etudiants;
    Enseignant** enseignants;
    int nbEtudiants, nbEnseignants, maxEt, maxEns;
public:
    Departement(int me = 100, int mens = 20)           // Q15
        : nbEtudiants(0), nbEnseignants(0), maxEt(me), maxEns(mens) {
        etudiants = new Etudiant*[maxEt];
        enseignants = new Enseignant*[maxEns];
    }
    ~Departement() { delete[] etudiants; delete[] enseignants; }
    Departement(const Departement&) = delete;
    Departement& operator=(const Departement&) = delete;
    void AjouterEtudiant(Etudiant* e) {                // Q16
        if (nbEtudiants < maxEt) etudiants[nbEtudiants++] = e;
    }
    void AjouterEnseignant(Enseignant* e) {            // Q17
        if (nbEnseignants < maxEns) enseignants[nbEnseignants++] = e;
    }
    void EnleverEtudiant(Etudiant* e) {                // Q18
        for (int i = 0; i < nbEtudiants; i++)
            if (etudiants[i] == e) {
                etudiants[i] = etudiants[--nbEtudiants]; // l'ordre n'a pas d'importance
                return;
            }
    }
    int EffectifEtudiants() const { return nbEtudiants; } // Q19
    void Affiche() const {
        for (int i = 0; i < nbEnseignants; i++) enseignants[i]->Affiche();
        for (int i = 0; i < nbEtudiants; i++) etudiants[i]->Affiche();
    }
};

int main() {
    Etudiant e1("Idrissi", "Ali", "ali@usms.ma", 2022, "G1");
    Etudiant e2("Bennani", "Hiba", "hiba@usms.ma", 2022, "G2");
    Enseignant p1("Safi", "Karim", "safi@usms.ma", "C++");
    Individu* tab[2] = { &e1, &p1 };
    for (Individu* i : tab) i->Affiche();   // liaison dynamique
    Departement info;
    info.AjouterEtudiant(&e1);
    info.AjouterEtudiant(&e2);
    info.AjouterEnseignant(&p1);
    cout << "Effectif : " << info.EffectifEtudiants() << endl;
    info.EnleverEtudiant(&e1);
    cout << "Effectif : " << info.EffectifEtudiants() << endl;
    info.Affiche();
    return 0;
}
```

```sortie
Etudiant : Ali Idrissi <ali@usms.ma>, promo 2022, groupe G1
Enseignant : Karim Safi <safi@usms.ma>, matiere C++
Effectif : 2
Effectif : 1
Enseignant : Karim Safi <safi@usms.ma>, matiere C++
Etudiant : Hiba Bennani <hiba@usms.ma>, promo 2022, groupe G2
```

> [!piege] Oublier `virtual` devant `Affiche()` dans `Individu` : la boucle sur `Individu*` afficherait alors deux fois la version de la base, sans promo ni matière.

```exercice Questions de l'examen 2021-2022
? Q10 : écris le constructeur d'`Etudiant` qui initialise tous les attributs.
= `Etudiant(string n, string p, string m, int pr, string g) : Individu(n, p, m), Promo(pr), groupe(g) {}` : la partie `Individu` est construite par le constructeur de la base, dans la liste d'initialisation.

? Q9 : comment `Etudiant::Affiche()` réutilise-t-elle l'affichage de la base ?
= En appelant `Individu::Affiche();` (opérateur de résolution de portée), puis en affichant `Promo` et `groupe`.

? Q5 : le constructeur de recopie d'`Individu` est-il indispensable ici ?
= Non : les attributs sont des `string`, qui savent se recopier. La recopie par défaut suffit ; on l'écrit parce que le sujet la demande. Elle devient indispensable dès qu'il y a un pointeur avec `new`.

? Q18 : `EnleverEtudiant` doit-elle faire `delete` sur l'étudiant ?
= Non : le département ne fait que **référencer** des étudiants créés ailleurs (ici sur la pile). Un `delete` sur un objet non alloué par `new` est une erreur.
```

## Flashcards

```cartes
Affiche() sur un objet constant :: la méthode doit être déclarée `const`.
operator= :: test `this != &x`, copie, `return *this` ; renvoie une référence.
Valeurs par défaut :: dans la déclaration : `Commande(Client c = Client(), string ref = "")`.
Composition par pointeurs :: tableau `T**` + compteur + capacité ; le conteneur ne détruit pas ce qu'il ne possède pas.
Constructeur dérivé :: `Derivee(...) : Base(...), attr(...) {}`.
Appeler la version de la base :: `Base::methode();`.
Redéfinition polymorphe :: `virtual` dans la base, même signature dans la dérivée.
Classe avec new :: destructeur + recopie + affectation (ou `= delete`).
```

## QCM du chapitre

```qcm
? Quelle signature permet d'appeler `Affiche()` sur un `const Client` ?
- void Affiche()
+ void Affiche() const
- const void Affiche()
= Le `const` après la parenthèse s'applique à l'objet courant (`this`).

? Que doit renvoyer `operator=` pour permettre `a = b = c` ?
- void
- Client (par valeur)
+ Client& (*this)
= On renvoie une référence sur l'objet modifié.

? Où écrit-on les valeurs par défaut d'un constructeur ?
+ Dans sa déclaration (prototype)
- Dans le corps du constructeur
- Dans le main
= Elles appartiennent à la déclaration ; on ne les répète pas dans la définition séparée.

? Dans `Etudiant(...) : Individu(n, p, m), Promo(pr)`, qui est construit en premier ?
+ La partie Individu
- Promo
- groupe
= La base est toujours construite avant les membres de la dérivée.

? Un `Individu* p = &etudiant; p->Affiche();` appelle `Etudiant::Affiche` si :
- Affiche est publique
+ Affiche est virtual dans Individu
- Etudiant hérite en protected
= Sans `virtual`, c'est le type du pointeur qui décide.

? Pourquoi `LigneCommande` garde-t-elle un `Article*` sans le détruire ?
+ L'article existe en dehors de la ligne (il ne lui appartient pas)
- Parce que delete est interdit dans une classe
- Pour gagner de la mémoire sur la pile
= Le propriétaire (ici le main) crée et détruit l'article.

? Que fait `Commande(const Commande&) = delete;` ?
- Il détruit la commande
+ Il interdit la copie d'une commande
- Il crée une copie vide
= Toute tentative de copie devient une erreur de compilation.

? Pour enlever l'élément d'indice i d'un tableau de n pointeurs en gardant l'ordre :
- on fait delete tab[i]
+ on décale tab[j] = tab[j+1] pour j de i à n−2, puis n--
- on met tab[i] = nullptr sans changer n
= Le décalage supprime le trou ; n diminue de 1.

? Les attributs d'`Individu` doivent être lisibles directement dans `Etudiant`. On les déclare :
- private
+ protected
- static
= protected : accessibles aux classes dérivées, pas à l'extérieur.

? Combien d'appels de constructeur de recopie dans `Client c2 = c1;` ?
- 0
+ 1
- 2
= Une déclaration avec initialisation par un objet du même type appelle la recopie (pas `operator=`).
```
