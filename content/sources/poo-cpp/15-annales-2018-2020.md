## 2018-2019 normale · Personne à char*, Employé (1 h 45)

**Énoncé (résumé).** `Personne` avec `char *nom, *prenom` (protected) : 1) constructeur qui réserve la mémoire ; 2) recopie ; 3) `Afficher` ; 4) `=` ; 5) destructeur ; 6) `==`. `Employé` dérivée avec `Salaire` (double) : 7) constructeur ; 8) recopie ; 9) `Afficher` redéfinie ; 10) `=` ; 11) `<<`.

```cpp
#include <iostream>
#include <cstring>
using namespace std;

class Personne {
protected:
    char* nom;
    char* prenom;
    static char* copie(const char* s) {            // alloue et recopie une chaîne
        char* r = new char[strlen(s) + 1];
        strcpy(r, s);
        return r;
    }
public:
    Personne(const char* a = "", const char* b = "") : nom(copie(a)), prenom(copie(b)) {} // 1)
    Personne(const Personne& p) : nom(copie(p.nom)), prenom(copie(p.prenom)) {}          // 2)
    virtual void Afficher() const { cout << prenom << " " << nom; }                      // 3)
    Personne& operator=(const Personne& p) {                                             // 4)
        if (this != &p) {
            delete[] nom; delete[] prenom;
            nom = copie(p.nom); prenom = copie(p.prenom);
        }
        return *this;
    }
    virtual ~Personne() { delete[] nom; delete[] prenom; }                               // 5)
    bool operator==(const Personne& p) const {                                           // 6)
        return strcmp(nom, p.nom) == 0 && strcmp(prenom, p.prenom) == 0;
    }
};

class Employe : public Personne {
    double Salaire;
public:
    Employe(const char* a = "", const char* b = "", double s = 0) : Personne(a, b), Salaire(s) {} // 7)
    Employe(const Employe& e) : Personne(e), Salaire(e.Salaire) {}                       // 8)
    void Afficher() const override { Personne::Afficher(); cout << ", salaire " << Salaire; } // 9)
    Employe& operator=(const Employe& e) {                                               // 10)
        if (this != &e) { Personne::operator=(e); Salaire = e.Salaire; }
        return *this;
    }
    friend ostream& operator<<(ostream& os, const Employe& e) {                         // 11)
        return os << e.prenom << " " << e.nom << " (" << e.Salaire << " DH)";
    }
};

int main() {
    Personne p1("Alami", "Rachid"), p2 = p1;
    cout << "p1 == p2 : " << (p1 == p2) << endl;
    p2 = Personne("Tazi", "Imane");
    p2.Afficher(); cout << endl;
    Employe e1("Fassi", "Kamal", 8000), e2;
    e2 = e1;
    cout << e2 << endl;
    Personne* q = &e1;
    q->Afficher(); cout << endl;
    return 0;
}
```

```sortie
p1 == p2 : 1
Imane Tazi
Kamal Fassi (8000 DH)
Kamal Fassi, salaire 8000
```

```exercice Questions clés
? Q1 : pourquoi `new char[strlen(s) + 1]` ?
= Il faut une case de plus pour le caractère de fin `'\0'` que `strcpy` recopie.

? Q8 : comment la recopie d'`Employe` recopie-t-elle la partie Personne ?
= Dans la liste d'initialisation : `Employe(const Employe& e) : Personne(e), Salaire(e.Salaire) {}`. Sans `Personne(e)`, c'est le constructeur **par défaut** de Personne qui serait appelé (nom vide).

? Q10 : et l'affectation d'`Employe` ?
= `Personne::operator=(e);` pour les chaînes, puis `Salaire = e.Salaire;`, le tout sous `if (this != &e)`, et `return *this;`.

? Q6 : pourquoi `strcmp` et pas `nom == p.nom` ?
= `==` sur deux `char*` compare les **adresses**, pas le texte : deux copies profondes ne seraient jamais égales.
```

## 2018-2019 rattrapage · Client et Compte (1 h)

**Énoncé (résumé).** `Client` (Nom, Prénom, CIN : string) : accesseurs, mutateurs, constructeur, recopie, `=`, `Afficher`. `Compte` : un solde, un code incrémenté à chaque création et un propriétaire (Client) ; `CodeCompte()` et `getSolde()` en lecture seule ; constructeur ; `Crediter(somme)`, `Crediter(Compte c, somme)` (crédite ce compte et débite c), `Debiter(somme)`, `Debiter(Compte c, somme)` (débite ce compte et crédite c) ; `Afficher` ; méthode **static** affichant le nombre de comptes créés ; programme de test.

```cpp
#include <iostream>
#include <string>
using namespace std;

class Client {
    string Nom, Prenom, CIN;
public:
    Client(string n = "", string p = "", string c = "") : Nom(n), Prenom(p), CIN(c) {} // 3)
    Client(const Client& c) : Nom(c.Nom), Prenom(c.Prenom), CIN(c.CIN) {}             // 4)
    void setNom(string n) { Nom = n; }                                                 // 2)
    void setPrenom(string p) { Prenom = p; }
    void setCIN(string c) { CIN = c; }
    string getNom() const { return Nom; }
    string getPrenom() const { return Prenom; }
    string getCIN() const { return CIN; }
    Client& operator=(const Client& c) {                                               // 5)
        if (this != &c) { Nom = c.Nom; Prenom = c.Prenom; CIN = c.CIN; }
        return *this;
    }
    void Afficher() const { cout << Prenom << " " << Nom << " (CIN " << CIN << ")"; }  // 6)
};

class Compte {                                                                         // 7)
    double solde;
    int code;
    Client* proprietaire;            // le client existe en dehors du compte
    static int nbComptes;            // compteur : sert aussi à numéroter
public:
    Compte(Client* c, double s = 0) : solde(s), code(++nbComptes), proprietaire(c) {}  // 9)
    int CodeCompte() const { return code; }                                            // 8) lecture seule
    double getSolde() const { return solde; }
    void Crediter(double somme) { solde += somme; }                                    // 10)
    void Crediter(Compte& c, double somme) { c.Debiter(somme); Crediter(somme); }      // 11)
    void Debiter(double somme) { solde -= somme; }                                     // 12)
    void Debiter(Compte& c, double somme) { Debiter(somme); c.Crediter(somme); }       // 13)
    void Afficher() const {                                                            // 14)
        cout << "Compte " << code << " de "; proprietaire->Afficher();
        cout << " : " << solde << " DH" << endl;
    }
    static void AfficherNombre() { cout << "Comptes crees : " << nbComptes << endl; }  // 15)
};
int Compte::nbComptes = 0;

int main() {                                                                           // 16)
    Client c1("Ayoub", "Fouad", "B12345"), c2("Benali", "Adam", "I67890");
    Compte cp1(&c1, 20000), cp2(&c2);
    cp2.Crediter(cp1, 5000);         // cp2 reçoit 5000 pris sur cp1
    cp1.Debiter(cp2, 1000);          // cp1 donne 1000 à cp2
    cp1.Afficher();
    cp2.Afficher();
    Compte::AfficherNombre();
    return 0;
}
```

```sortie
Compte 1 de Fouad Ayoub (CIN B12345) : 14000 DH
Compte 2 de Adam Benali (CIN I67890) : 6000 DH
Comptes crees : 2
```

```exercice Questions clés
? Comment le code est-il « incrémenté lors de la création » ?
= Un compteur `static int nbComptes` partagé ; le constructeur fait `code(++nbComptes)`. Le premier compte a le code 1, le deuxième 2.

? Pourquoi passer le compte par **référence** dans `Crediter(Compte& c, double)` ?
= Par valeur, on débiterait une **copie** : le vrai compte c ne changerait pas.

? Soldes finaux : cp1 à 20 000, cp2 à 0 ; `cp2.Crediter(cp1, 5000)` puis `cp1.Debiter(cp2, 1000)`.
= cp1 : 20 000 − 5 000 − 1 000 = **14 000** ; cp2 : 5 000 + 1 000 = **6 000**.
reponse: 14000
```

## 2019-2020 rattrapage · Rationnel à pointeurs (1 h 30)

**Énoncé (résumé).** `class Rationnel { int *num; int *den; ... }` avec 21 méthodes imposées : constructeur `(int = 0, int = 1)`, recopie, destructeur, `Affichage`, `GetNum`/`GetDen`, `SetNum`/`SetDen`, `Invertir`, `Réduire`, `+`, moins unaire, `-`, `*`, `/`, `^(unsigned)`, `=`, `==`, `<`, `>`, `operator double`, `<<` et `>>` amis.

```cpp
#include <iostream>
using namespace std;

class Rationnel {
    int* num;
    int* den;
    static int pgcd(int a, int b) {
        if (a < 0) a = -a;
        if (b < 0) b = -b;
        while (b) { int t = a % b; a = b; b = t; }
        return a ? a : 1;
    }
public:
    Rationnel(int n = 0, int d = 1) : num(new int(n)), den(new int(d)) { Reduire(); } // 1)
    Rationnel(const Rationnel& r) : num(new int(*r.num)), den(new int(*r.den)) {}     // 2)
    ~Rationnel() { delete num; delete den; }                                          // 3)
    void Affichage() const { cout << *num << "/" << *den << endl; }                   // 4)
    int GetNum() const { return *num; }                                               // 5)
    int GetDen() const { return *den; }
    void SetNum(int n) { *num = n; }                                                  // 6)
    void SetDen(int d) { *den = d; }
    void Invertir() { int t = *num; *num = *den; *den = t; Reduire(); }               // 7)
    void Reduire() {                                                                  // 8)
        if (*den < 0) { *num = -*num; *den = -*den; }
        int g = pgcd(*num, *den);
        *num /= g; *den /= g;
    }
    Rationnel operator+(const Rationnel& r) const { return Rationnel(*num * *r.den + *r.num * *den, *den * *r.den); } // 9)
    Rationnel operator-() const { return Rationnel(-*num, *den); }                    // 10)
    Rationnel operator-(const Rationnel& r) const { return *this + (-r); }            // 11)
    Rationnel operator*(const Rationnel& r) const { return Rationnel(*num * *r.num, *den * *r.den); } // 12)
    Rationnel operator/(const Rationnel& r) const { return Rationnel(*num * *r.den, *den * *r.num); } // 13)
    Rationnel operator^(unsigned n) const {                                           // 14)
        Rationnel r(1);
        for (unsigned i = 0; i < n; i++) r = r * *this;
        return r;
    }
    Rationnel& operator=(const Rationnel& r) {                                        // 15)
        if (this != &r) { *num = *r.num; *den = *r.den; }   // on réutilise les int déjà alloués
        return *this;
    }
    int operator==(const Rationnel& r) const { return *num * *r.den == *r.num * *den; } // 16)
    int operator<(const Rationnel& r) const { return *num * *r.den < *r.num * *den; }  // 17) den > 0
    int operator>(const Rationnel& r) const { return r < *this; }                      // 18)
    operator double() const { return (double)*num / *den; }                            // 19)
    friend ostream& operator<<(ostream& os, const Rationnel& r) { return os << *r.num << "/" << *r.den; } // 20)
    friend istream& operator>>(istream& is, Rationnel& r) {                            // 21)
        is >> *r.num >> *r.den; r.Reduire(); return is;
    }
};

int main() {
    Rationnel a(6, -8), b(1, 2);
    Rationnel c = a;             // recopie profonde
    c.SetNum(5);
    cout << "a = " << a << ", c = " << c << endl;
    cout << "a + b = " << a + b << ", a - b = " << a - b << endl;
    cout << "a * b = " << a * b << ", a / b = " << a / b << endl;
    cout << "b ^ 3 = " << (b ^ 3u) << endl;
    cout << "a < b : " << (a < b) << ", a > b : " << (a > b) << endl;
    b.Invertir(); cout << "b inverse = " << b << ", en double : " << (double)a << endl;
    return 0;
}
```

```sortie
a = -3/4, c = 5/4
a + b = -1/4, a - b = -5/4
a * b = -3/8, a / b = -3/2
b ^ 3 = 1/8
a < b : 1, a > b : 0
b inverse = 2/1, en double : -0.75
```

> [!retenir] Ici les attributs sont des **pointeurs** : sans recopie profonde, `c = a` puis `c.SetNum(5)` modifierait aussi `a`. La sortie montre a = −3/4 et c = 5/4 : les deux objets sont bien indépendants.

> [!attention] Le sujet écrit `Invertir` et `Réduire` (avec accent) : un identifiant C++ ne peut pas contenir d'accent de façon portable, on écrit `Reduire`. Pour `<` et `>`, la comparaison par produits en croix suppose des dénominateurs positifs : c'est pour cela que `Reduire` remet le signe au numérateur.

## Flashcards

```cartes
Chaîne char* dans une classe :: `new char[strlen(s)+1]` + `strcpy`, `delete[]` dans le destructeur.
Comparer deux char* :: `strcmp(a, b) == 0`, jamais `a == b`.
Recopie d'une dérivée :: `Derivee(const Derivee& d) : Base(d), ... {}`.
Affectation d'une dérivée :: `Base::operator=(d);` puis les membres propres.
Numéro auto-incrémenté :: compteur static, `code(++compteur)` dans le constructeur.
Modifier un objet passé en paramètre :: le passer par référence.
Méthode static :: appelée par `Classe::methode()`, sans objet, n'accède qu'aux membres static.
a/b < c/d (b, d > 0) :: a·d < c·b.
```

## QCM du chapitre

```qcm
? Taille à allouer pour copier "Alami" dans un char* :
- 5
+ 6
- 4
= 5 lettres + le '\0'.

? Avec deux `char*` de même texte copiés séparément, `nom == p.nom` vaut :
+ faux (adresses différentes)
- vrai
- erreur de compilation
= On compare des pointeurs.

? Dans la recopie d'`Employe`, oublier `: Personne(e)` provoque :
- une erreur de compilation
+ l'appel du constructeur par défaut de Personne
- une double libération
= La partie base est construite par défaut.

? Le constructeur d'un Compte qui numérote automatiquement contient :
+ code(++nbComptes)
- code(nbComptes--)
- code(0)
= Le compteur static avance à chaque création.

? `void Crediter(Compte c, double s)` (par valeur) débite :
- le compte passé
+ une copie, le compte d'origine ne change pas
- les deux
= Il faut `Compte&`.

? Une méthode static peut accéder :
- à tous les membres de l'objet courant
+ seulement aux membres static (pas de this)
- uniquement aux membres privés
= Elle n'est liée à aucun objet.

? Rationnel(6, −8) réduit vaut :
+ −3/4
- 3/−4
- 6/−8

? (1/2)^3 vaut :
- 3/2
+ 1/8
- 1/6
= 1³/2³.

? Avec `int *num`, l'affectation `operator=` doit :
+ recopier les valeurs pointées (*num = *r.num)
- recopier les pointeurs (num = r.num)
- ne rien faire
= Sinon partage et double libération.
```
