```html
<p>Le processeur (CPU) lit une instruction en mémoire, l'interprète (décode), lit les données, les traite, et écrit le résultat. Il contient 4 éléments :</p>
<ul><li><b>Unité de contrôle (séquenceur)</b> : décode les instructions, choisit les registres, gère les interruptions, initialise au démarrage.</li>
<li><b>UAL</b> (unité arithmétique et logique) : fait les calculs et les opérations logiques.</li>
<li><b>Registres</b> : mémoires internes temporaires.</li>
<li><b>Bus interne</b> : relie ces éléments.</li></ul>
<h4>Cycle d'exécution d'une instruction</h4>
<ol><li><b>Recherche</b> : le CO (compteur ordinal, PC, ou IP sur le 8086) contient l'adresse de l'instruction suivante ; l'unité de commande la place sur le bus d'adresses et émet un ordre de lecture ; l'instruction arrive par le bus de données dans le <b>RI</b> (registre d'instruction).</li>
<li><b>Décodage</b> : l'unité de contrôle identifie l'opération, analyse les champs (sources, destination) et génère les signaux de commande.</li>
<li><b>Exécution</b> : l'opération est faite, les <b>drapeaux</b> sont positionnés, puis le CO est mis à jour vers l'instruction suivante.</li></ol>
<div class="def"><b>Tailles de registres (TD 3 ex. 5 et 6)</b><b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">CO</b> contient une <b>adresse</b> de mot mémoire : taille(CO) = ⌈log₂(nombre de mots)⌉.<br>
<b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">Code opération</b> : ⌈log₂(nombre d'opérations)⌉ bits.<br>
<b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">RI</b> contient une instruction = code op + champs d'adresse. Format à 3 adresses (celui du corrigé 2024) : code op | @op1 | @op2 | @résultat → taille min(RI) = code op + 3 × taille d'adresse.<br>
<b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">Taille réelle</b> : le RI reçoit un mot mémoire entier, donc taille réelle(RI) = taille d'un mot = capacité (bits) / nombre de mots.</div>
<details class="ex"><summary>Exemple guidé : TD 3 ex. 5 (64 mots, 13 opérations, RAM de 192 octets)</summary><div><div class="steps">1. CO : 64 = 2⁶ → 6 bits
2. Code op : 13 opérations, 2³ = 8 &lt; 13 ≤ 16 = 2⁴ → 4 bits
   Adresse : 6 bits ; format à 3 adresses → RI min = 4 + 3 × 6 = 22 bits
3. Mot = 192 × 8 / 64 = 24 bits → taille réelle de RI = 24 bits (22 ≤ 24 ✓)</div>
<div class="trap"><b>Piège du corrigé 2024</b>Il calcule taille(CO) = log₂(13) = 4 bits : il confond le CO (une adresse d'instruction) et le code opération. La bonne réponse est <b>6 bits</b>. Pour le RI, le format (1, 2 ou 3 adresses) dépend du cours oral : 22 bits avec 3 adresses ; si le prof utilise un format à 1 adresse, ce serait 4 + 6 = 10 bits. Écris le format que tu supposes.</div></div></details>
<details class="ex"><summary>Exemple guidé : TD 3 ex. 6 (11 opérations 0000 à 1010, CO = 00011)</summary><div><div class="steps">Code op sur 4 bits (codes 0000 à 1010)
CO affiché sur 5 bits → adresses de 5 bits
1. RI (3 adresses) = 4 + 3 × 5 = 19 bits
2. Nombre maximal de mots = 2⁵ = 32 mots</div></div></details>
<h4>CISC et RISC</h4>
<div class="table-wrap"><table><tr><th></th><th>CISC (Intel x86, AMD x86)</th><th>RISC (ARM, PowerPC, MIPS, RISC-V)</th></tr>
<tr><td>Jeu d'instructions</td><td>Complexe, souvent plus de 200 instructions</td><td>Réduit, moins de 100 (les 20 % d'instructions qui font 80 % du travail)</td></tr>
<tr><td>Câblage</td><td>Complexe, peut ralentir</td><td>Simple, plus rapide</td></tr>
<tr><td>Avantage</td><td>Programmation en assembleur plus simple</td><td>Exécution plus rapide</td></tr>
<tr><td>Inconvénient</td><td>Instructions plus longues à exécuter</td><td>Compilateur plus complexe</td></tr></table></div>
<h4>Puissance</h4>
<p>L'horloge produit des « tops » (fréquence en Hz). <b>CPI</b> = nombre moyen de cycles par instruction ; unité de puissance : <b>MIPS</b> (millions d'instructions par seconde). MIPS = fréquence (MHz) / CPI. Pour améliorer : augmenter la fréquence (limite matérielle) ou diminuer le CPI (jeu d'instructions adapté).</p>
<h4>Mémoire cache</h4>
<p>Le CPU demande une donnée ; si elle est dans le cache : <b>succès</b> (hit) ; sinon <b>défaut</b> (miss) : le cache la demande à la mémoire principale, la garde et la transmet. Elle exploite la <b>localité spatiale</b> (après l'adresse x, on accède probablement à une adresse proche de x) et la <b>localité temporelle</b> (une zone accédée sera probablement réaccédée bientôt).</p>
<h4>Le 8086</h4>
<p>Deux unités qui travaillent en parallèle : la <b>BIU</b> (unité d'interface de bus) cherche les instructions en mémoire et les range dans une file d'attente ; l'<b>EU</b> (unité d'exécution) les exécute.</p>
<div class="table-wrap"><table><tr><th>Groupe</th><th>Registres (16 bits)</th></tr>
<tr><td>Généraux</td><td><b>AX</b> accumulateur (AH|AL) · <b>BX</b> base (BH|BL) · <b>CX</b> compteur (CH|CL) · <b>DX</b> données (DH|DL)</td></tr>
<tr><td>Pointeurs et index</td><td><b>SP</b> pointeur de pile · <b>BP</b> pointeur de base · <b>SI</b> index source · <b>DI</b> index destination</td></tr>
<tr><td>Segments</td><td><b>CS</b> code · <b>DS</b> données · <b>SS</b> pile · <b>ES</b> extra</td></tr>
<tr><td>Autres</td><td><b>IP</b> pointeur d'instruction (le CO) · <b>FLAGS</b> registre d'état</td></tr></table></div>
<div class="trap"><b>Piège du corrigé 2024 (TD 4 ex. 1)</b>Il écrit « SI = indice de pile, DI = indice de données ». C'est <b>SI = Source Index</b>, <b>DI = Destination Index</b>.</div>
<div class="formula">CF (Carry)    : retenue sortante (addition) ou emprunt (soustraction) en non signé
ZF (Zero)     : 1 si le résultat vaut 0
SF (Sign)     : copie du bit de poids fort du résultat (1 = négatif)
PF (Parity)   : 1 si l'octet de poids faible du résultat a un nombre PAIR de 1
OF (Overflow) : 1 si dépassement en signé (même signe en entrée, signe opposé en sortie)</div>
```

## Questions de rédaction

```exercice
? {n21} Décrire les 3 phases du cycle d'exécution d'une instruction.
= Recherche : le CO (IP) donne l'adresse, placée sur le bus d'adresses, l'instruction revient par le bus de données dans le RI. Décodage : l'unité de contrôle identifie l'opération et les opérandes et génère les signaux. Exécution : l'UAL fait l'opération, les drapeaux sont positionnés, le CO passe à l'instruction suivante.
? {n21} Comparer les architectures CISC et RISC.
= CISC : jeu d'instructions complexe (plus de 200), programmation assembleur plus simple, câblage complexe, exécution plus lente (Intel x86). RISC : jeu réduit (moins de 100) aux instructions les plus utilisées (80/20), câblage simple, exécution plus rapide, compilateur plus complexe (ARM, MIPS).
? {n21} Expliquer le fonctionnement de la mémoire cache et les principes de localité.
= Le cache garde une copie des données les plus utilisées. Si la donnée demandée y est : succès ; sinon défaut de cache : on la lit en mémoire principale, on la garde dans le cache et on la transmet. Localité spatiale : après l'adresse x, on accède probablement à une adresse proche. Localité temporelle : une zone accédée le sera probablement de nouveau bientôt.
```

```cartes
{n21@52} Les 3 phases du cycle d'instruction ? :: Recherche (CO → bus d'adresses → instruction dans RI), décodage, exécution (drapeaux, mise à jour du CO).
{n21@53} Taille du CO ? :: ⌈log₂(nombre de mots mémoire)⌉ : il contient une adresse.
{n21@54} CISC vs RISC ? :: CISC : > 200 instructions complexes, programmation plus simple, exécution plus lente (x86).<br>RISC : < 100 instructions simples, plus rapide, compilateur plus complexe (ARM).

{n21@56} Puissance d'un processeur ? :: En MIPS. MIPS = fréquence (MHz) / CPI. On l'améliore en augmentant la fréquence ou en baissant le CPI.
{n22@57} BIU et EU du 8086 ? :: BIU : cherche les instructions et les met en file d'attente.<br>EU : les exécute. Les deux fonctionnent en même temps.
{n22@58} Registres généraux du 8086 ? :: AX accumulateur, BX base, CX compteur, DX données (chacun = H + L de 8 bits).
{n22@59} SI et DI ? :: Source Index et Destination Index (registres d'index).
{n22@60} CF, ZF, SF, OF, PF ? :: CF retenue/emprunt ; ZF résultat nul ; SF bit de signe ; OF dépassement signé ; PF nombre pair de 1 dans l'octet bas.
```
