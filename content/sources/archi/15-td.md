```exercice TD 2 · Algèbre de Boole
? {n9} **2.1a.** Exprimer ET avec OU et NON, puis OU avec ET et NON.
indice: De Morgan.
= A·B = (Ā + B̄)‾ · A + B = (Ā·B̄)‾
? {n9} **2.1b.** Montrer que A + Ā·B = A + B et que A·(Ā + B) = A·B.
indice: Distributivité du OU sur le ET pour la première.
= A + Ā·B = (A + Ā)(A + B) = A + B · A·(Ā + B) = A·Ā + A·B = A·B.
? {n9} **2.1c.** Complément de Ā + B·C.
indice: De Morgan deux fois, garde les parenthèses.
= (Ā + B·C)‾ = A·(B·C)‾ = A·(B̄ + C̄) = A·B̄ + A·C̄.
? {n9} **2.1d.** Montrer que les deux règles d'associativité sont duales.
indice: Complémente les deux membres de Ā + (B̄ + C̄) = (Ā + B̄) + C̄.
= (Ā + (B̄ + C̄))‾ = A·(B·C) et ((Ā + B̄) + C̄)‾ = (A·B)·C, donc A·(B·C) = (A·B)·C. Même raisonnement en sens inverse.
? {n9} **2.1e.** Écrire (A ⊕ B)‾ avec OU, ET, NON seulement.
indice: A ⊕ B = Ā·B + A·B̄, puis De Morgan.
= (A ⊕ B)‾ = (A + B̄)(Ā + B) = A·B + Ā·B̄.
? {n9} **2.1f.** Démontrer F(A,B,C) = A·F(1,B,C) + Ā·F(0,B,C).
indice: Deux cas : A = 0 et A = 1.
= A = 1 : 1·F(1,B,C) + 0 = F(1,B,C). A = 0 : 0 + 1·F(0,B,C) = F(0,B,C). Vrai dans les deux cas (théorème de Shannon).
? {n11} **2.2.** G(A,B,C) = A + B·C̄ : table de vérité, 1re et 2e formes canoniques.
indice: G = 1 si A = 1, ou si B = 1 et C = 0.
= G = 1 pour 010, 100, 101, 110, 111. 1re forme : Ā·B·C̄ + A·B̄·C̄ + A·B̄·C + A·B·C̄ + A·B·C. 2e forme : (A+B+C)(A+B+C̄)(A+B̄+C̄).
? {n12} **2.3.** H vaut 1 pour 001, 010, 100, 101, 110 : formes canoniques puis simplification de la 2e.
indice: H = 0 pour 000, 011, 111.
= 1re : Ā·B̄·C + Ā·B·C̄ + A·B̄·C̄ + A·B̄·C + A·B·C̄. 2e : (A+B+C)(A+B̄+C̄)(Ā+B̄+C̄). Simplifiée : (A+B+C)(B̄+C̄) = B⊕C + A·C̄ (ou B⊕C + A·B̄).
? {n10} **2.4.** Logigramme : deux inverseurs, deux ET, un OU donnent S ; un ET donne C. Expressions de S et C ?
indice: Lis chaque porte de gauche à droite.
= S = A·B̄ + Ā·B = A ⊕ B ; C = A·B. C'est un demi-additionneur.
? {n12} **2.5.** K = A·B̄·C + A·B·C̄ + Ā·B·C̄ + A·B·C : simplifier, logigramme, version NAND.
indice: Regroupe A·B̄·C avec A·B·C, et A·B·C̄ avec Ā·B·C̄.
= K = A·C + B·C̄ = NAND( NAND(A,C), NAND(B, NAND(C,C)) ).
? {n10} **2.6.** Avec seulement des NAND : NON, ET, OU, XOR et leurs circuits.
indice: NAND(A,A) = Ā.
= Ā = NAND(A,A) · A·B = NAND(N,N) avec N = NAND(A,B) · A+B = NAND(NAND(A,A),NAND(B,B)) · A⊕B = NAND(NAND(A,N),NAND(B,N)) (4 portes).
? {n13} **2.7.** Karnaugh : F1 = A·B̄·C + A·B·C̄ + A·B·C ; F2 = Ā·B̄·C̄ + A·B̄ + A·B·C ; F3 = Ā·B̄ + Ā·B·C̄ + B̄·C̄ + A·B̄·C ; F4 = B·C̄·D̄ + Ā·B·D̄ + A·B·C·D̄.
indice: Place les mintermes, cherche les plus grands rectangles.
= F1 = A·B + A·C · F2 = B̄·C̄ + A·C · F3 = B̄ + Ā·C̄ · F4 = B·D̄
```

```exercice TD 3 · Circuits, mémoire, processeur
? {n16} **3.1.** Circuit à rebouclage S (voir énoncé) : combinatoire ou séquentiel ? Expressions de F et Sn+1.
indice: Une sortie revient-elle en entrée ? Suis le fil de l'inverseur.
= Séquentiel (S est rebouclée). F = E1·E2 + (E1+E2)·S̄n ; Sn+1 = E1·E2 + (E1+E2)·Sn.
? {n15} **3.2.** Complément à 2 d'un nombre de 3 bits avec 3 MUX 8×1.
indice: Table : n → (8 − n) mod 8, une colonne par MUX.
= S2 : E1–E4 = 1 · S1 : E1, E2, E5, E6 = 1 · S0 : E1, E3, E5, E7 = 1 (les autres à 0). Commandes a, b, c communes.
? {n15} **3.3.** Parité d'un mot abc (0 si nombre de 1 pair) : table, MUX 8×1, DEMUX 1×8.
indice: F = a ⊕ b ⊕ c.
= F = 0 1 1 0 1 0 0 1. MUX : E1, E2, E4, E7 = 1. DEMUX (I = 1) : F = S1 + S2 + S4 + S7.
? {n1} **3.4.** Architecture de Von Neumann (schéma) ; définir unité centrale, microprocesseur, mémoire principale, bus, registre ; où sont programmes et données ?
indice: Leçon 1.
= Voir leçon 1 : 4 organes reliés par les bus ; programmes et données dans la même mémoire principale.
? {n21} **3.5.** RAM de 64 mots, 13 opérations : taille du CO, taille minimale du RI, taille réelle du RI si la RAM fait 192 octets.
indice: Le CO contient une adresse. Le RI contient code op + adresses.
= CO = 6 bits · code op = 4 bits, RI min = 4 + 3×6 = 22 bits (format à 3 adresses) · mot = 192×8/64 = 24 bits → RI réel = 24 bits.
? {n21} **3.6.** 11 opérations codées de 0000 à 1010, CO = 00011 : taille du RI ? Nombre maximal de mots ?
indice: Le CO fait 5 bits.
= RI = 4 + 3×5 = 19 bits (3 adresses) · 2⁵ = 32 mots.
? {n19} **3.7.** Interactions processeur-mémoire-bus pour : int A=2, B=4, C=3 ; D=A\*B ; E=C+D.
indice: Adresse → bus d'adresses ; valeur → bus de données ; calcul → UAL.
= Écriture de 2, 4, 3 (adresse sur le bus d'adresses, valeur sur le bus de données). D : lecture de A et B, calcul 8 par l'UAL, écriture à l'adresse de D. E : lecture de C et D, calcul 11, écriture à l'adresse de E. Chaque instruction est d'abord cherchée (CO → bus d'adresses → RI) et décodée.
```
