<h4>Les lois à connaître par cœur</h4>
<div class="formula">NON : double négation  Ā̄ = A      A + Ā = 1      A · Ā = 0
OU  : A+0 = A (neutre)  A+1 = 1 (absorbant)  A+A = A (idempotence)
ET  : A·1 = A (neutre)  A·0 = 0 (absorbant)  A·A = A (idempotence)
Commutativité, associativité : A+(B+C) = (A+B)+C   A·(B·C) = (A·B)·C
Distributivité : A·(B+C) = A·B + A·C     A + B·C = (A+B)·(A+C)   ← la 2e n'existe pas en algèbre classique
XOR : A⊕B = Ā·B + A·B̄
De Morgan : (A+B)‾ = Ā·B̄      (A·B)‾ = Ā + B̄     (valable pour n variables)
Dualité : une égalité reste vraie si on échange ET↔OU et 0↔1 (A+1 = 1 ⇔ A·0 = 0)</div>
<div class="def"><b>Règles de simplification du cours (diapo 32)</b>A·B + A·B̄ = A &nbsp;·&nbsp; A + A·B = A &nbsp;·&nbsp; A + Ā·B = A + B &nbsp;·&nbsp; (A+B)(A+B̄) = A &nbsp;·&nbsp; A·(A+B) = A &nbsp;·&nbsp; A·(Ā+B) = A·B</div>
<details class="ex"><summary>Exemple guidé : TD 2 ex. 1</summary><div><div class="steps">1. A·B = (Ā + B̄)‾      A + B = (Ā · B̄)‾          (De Morgan)
2. A + Ā·B = (A + Ā)(A + B) = 1·(A + B) = A + B   (distributivité du OU sur le ET)
   A·(Ā + B) = A·Ā + A·B = 0 + A·B = A·B
3. (Ā + B·C)‾ = A · (B·C)‾ = A · (B̄ + C̄)
4. Dualité de l'associativité : on part de Ā+(B̄+C̄) = (Ā+B̄)+C̄, on complémente les deux côtés,
   De Morgan donne A·(B·C) = (A·B)·C. Et inversement.
5. (A⊕B)‾ = (Ā·B + A·B̄)‾ = (A + B̄)·(Ā + B) = A·B + Ā·B̄   (XNOR)
6. Si A = 1 : 1·F(1,B,C) + 0·F(0,B,C) = F(1,B,C) ✓ ; si A = 0 : F(0,B,C) ✓
   (décomposition de Shannon, base du multiplexeur)</div>
<div class="trap"><b>Pièges du corrigé 2024</b>Q3 : il écrit A·B̄ + C̄, ce qui vaut (A·B̄) + C̄ : il manque les parenthèses, le résultat est faux. Écris A·(B̄ + C̄). Q2 : il écrit « A + Ā·A + B », notation fausse de (A + Ā)(A + B).</div></div></details>
<h4>NAND et NOR sont « complets »</h4>
<p>Avec seulement des NAND (ou seulement des NOR), on peut construire NON, ET, OU, donc n'importe quelle fonction.</p>
<div class="formula">NON : Ā = (A·A)‾                         = NAND(A, A)
ET  : A·B = ((A·B)‾)‾                    = NAND(NAND(A,B), NAND(A,B))
OU  : A+B = (Ā·B̄)‾                       = NAND(NAND(A,A), NAND(B,B))
XOR : A⊕B, avec N = NAND(A,B) :  A⊕B = NAND( NAND(A,N), NAND(B,N) )   (4 portes NAND)
Méthode générale : écrire F en somme de produits, puis F = ((F)‾)‾ et appliquer De Morgan une fois :
  A·C + B·C̄ = ( (A·C)‾ · (B·C̄)‾ )‾ = NAND( NAND(A,C), NAND(B, C̄) )</div>
<h4>Logigramme</h4>
<p>Traduire la fonction en schéma : chaque opérateur devient une porte. Pour lire un logigramme, écris la sortie de chaque porte de gauche à droite. Exemple du cours : F(A,B,C) = A·B + B̄·C (une porte ET, une porte NON, une porte ET, une porte OU).</p>
<details class="ex"><summary>Exemple guidé : TD 2 ex. 4 (logigramme à deux sorties)</summary><div>
<p>Les deux inverseurs donnent Ā et B̄. Les deux portes ET du haut donnent A·B̄ et Ā·B, la porte OU donne <b>S = A·B̄ + Ā·B = A ⊕ B</b>. La porte ET du bas donne <b>C = A·B</b>. C'est un <b>demi-additionneur</b> : S est la somme et C la retenue (Carry).</p></div></details>
