```html
<h4>Unités</h4>
<div class="formula">bit      : 0 ou 1 (BInary digIT), plus petite unité
quartet  : 4 bits
octet    : 8 bits → 2⁸ = 256 valeurs
1 Ko = 1024 octets   1 Mo = 1024 Ko   1 Go = 1024 Mo   1 To = 1024 Go   (cours : puissances de 2)</div>
<div class="def"><b>La règle qui sert partout</b>Sur <b>n bits</b> on code <b>2ⁿ valeurs</b> : les entiers non signés de 0 à 2ⁿ − 1.<br>Pour coder <b>N valeurs différentes</b>, il faut le plus petit n tel que 2ⁿ ≥ N, c'est-à-dire n = ⌈log₂ N⌉.</div>
<details class="ex"><summary>Exemple guidé : TD 1 ex. 1</summary><div>
<p>1. Sur un octet : 2⁸ = <b>256 entiers positifs</b>, de 0 à 255.</p>
<p>2. 65 563 valeurs : 2¹⁶ = 65 536 &lt; 65 563 ≤ 2¹⁷ = 131 072 → <b>17 bits</b>.</p>
<p>3. 4 Mo = 4 × 2²⁰ octets ; un mot = 32 bits = 4 octets → 4 × 2²⁰ / 4 = 2²⁰ = <b>1 048 576 mots</b>.</p>
<div class="trap"><b>Piège</b>Le corrigé 2024 écrit « de 0 à 256 » : c'est faux, le plus grand est 255 (256 valeurs en comptant 0).</div></div></details>
<h4>Écrire un nombre dans une base</h4>
<p>Dans la base b, on utilise b symboles (0 … b−1) et chaque position vaut une puissance de b. C'est la <b>forme polynomiale</b> :</p>
<div class="formula">(1101,101)₂ = 1·2³ + 1·2² + 0·2¹ + 1·2⁰ + 1·2⁻¹ + 0·2⁻² + 1·2⁻³ = 13,625
(1A7)₁₆    = 1·16² + 10·16¹ + 7·16⁰ = 256 + 160 + 7 = 423
(43,2)₅    = 4·5 + 3 + 2·5⁻¹ = 23,4</div>
<p>Hexadécimal : A=10, B=11, C=12, D=13, E=14, F=15. Un chiffre qui n'existe pas dans la base rend le nombre invalide : (1289)₈ n'existe pas.</p>
<h4>Les 4 méthodes de conversion</h4>
<ol>
<li><b>Base b → décimal</b> : développer en polynôme et additionner.</li>
<li><b>Décimal → base b (partie entière)</b> : divisions successives par b, on lit les <b>restes de bas en haut</b>.</li>
<li><b>Décimal → base b (partie fractionnaire)</b> : multiplications successives par b, on lit les <b>parties entières de haut en bas</b>. On s'arrête quand la partie fractionnaire vaut 0 ou quand on a assez de chiffres (le résultat peut être infini).</li>
<li><b>b1 → b2</b> : passer par la base 10. <b>Exception</b> : entre 2, 8 et 16, on regroupe les bits (3 bits = 1 chiffre octal, 4 bits = 1 chiffre hexa), à partir de la virgule : vers la gauche pour la partie entière, vers la droite pour la partie fractionnaire, en complétant avec des 0.</li></ol>
<details class="ex"><summary>Exemple guidé : (35,625)₁₀ en binaire</summary><div><div class="steps">Partie entière, divisions par 2 :
35 = 2×17 + 1
17 = 2×8  + 1
 8 = 2×4  + 0
 4 = 2×2  + 0
 2 = 2×1  + 0
 1 = 2×0  + 1      restes lus de bas en haut → 100011

Partie fractionnaire, multiplications par 2 :
0,625 × 2 = 1,25  → 1
0,25  × 2 = 0,5   → 0
0,5   × 2 = 1,0   → 1   (fin : partie fractionnaire nulle)
lu de haut en bas → ,101

(35,625)₁₀ = (100011,101)₂</div></div></details>
<details class="ex"><summary>Exemple guidé : regroupements</summary><div><div class="steps">(110010100,10101)₂ en octal : 110 010 100 , 101 010 → (624,52)₈
(110010100,10101)₂ en hexa  : 0001 1001 0100 , 1010 1000 → (194,A8)₁₆
(AB3,4F6)₁₆ en binaire : 1010 1011 0011 , 0100 1111 0110
(34)₅ en base 7 : 3×5+4 = 19 ; 19 = 7×2+5 ; 2 = 7×0+2 → (25)₇</div>
<div class="trap"><b>Erreur dans les diapos</b>Diapo 27 : « (43)₁₀ = (101011)₂ = (AB)₁₆ ». Faux : 0010 1011 = <b>(2B)₁₆</b>. Et la diapo 23 donne (624,51)₈ : avec le regroupement à droite on obtient 101 010 = <b>(624,52)₈</b>.</div></div></details>
<details class="ex"><summary>Exemple guidé : TD 1 ex. 2.3, trouver une base</summary><div>
<p>(2545)<sub>b</sub> = (4)₁₀ ? Le nombre contient le chiffre 5, donc b ≥ 6. Alors (2545)<sub>b</sub> ≥ 2·6³ = 432 &gt; 4. <b>Aucune base ne convient.</b></p>
<p>La méthode longue (résoudre 2b³ + 5b² + 4b + 5 = 4, racines −1 et −½, aucune base entière ≥ 2) donne la même conclusion. L'argument « chiffre 5 donc b ≥ 6 » se rédige en deux lignes : utilise-le.</p></div></details>
<div class="trap"><b>Piège du TD 1</b>(26,3)₁₀ = (<b>11010</b>,0100110011…)₂ : 26 = 16 + 8 + 2. Le corrigé 2024 écrit 10010 (qui vaut 18) : erreur de recopie. Et 0,3 donne un développement infini (0,0 1001 1001…) : on s'arrête à la précision demandée et on l'écrit.</div>
```

## Flashcards

```cartes
{n2@6} Combien de valeurs sur n bits ? :: 2ⁿ valeurs ; en non signé de 0 à 2ⁿ − 1.
{n2@7} Combien de bits pour N valeurs ? :: Le plus petit n avec 2ⁿ ≥ N : n = ⌈log₂ N⌉. Ex. 65 563 → 17 bits.
{n2@8} 1 Mo en octets (cours) ? :: 1 Mo = 1024 Ko = 2²⁰ = 1 048 576 octets.
{n3@9} Méthode décimal → base b ? :: Divisions successives par b ; on lit les restes de bas en haut (le dernier reste est le poids fort).
{n3@10} Binaire ↔ octal / hexa ? :: Regrouper par 3 (octal) ou 4 (hexa) à partir de la virgule, compléter avec des 0.
{n4@11} Partie fractionnaire décimal → binaire ? :: Multiplications successives par 2, on lit les parties entières de haut en bas. Peut être infini (0,3).
```
