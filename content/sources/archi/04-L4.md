```html
<p>Le processeur ne connaît pas le signe « − ». Le cours présente 3 conventions, toujours sur un nombre de bits <b>n fixé</b>.</p>
<div class="table-wrap"><table><tr><th>Méthode</th><th>Codage de −x</th><th>Plage sur n bits</th><th>Zéro</th></tr>
<tr><td><b>Signe / valeur absolue</b> (S/VA)</td><td>bit de poids fort = 1, puis |x| sur n−1 bits</td><td class="num">−(2ⁿ⁻¹−1) … +(2ⁿ⁻¹−1)</td><td>deux zéros (+0, −0)</td></tr>
<tr><td><b>Complément à 1</b> (restreint, Ca1)</td><td>inverser tous les bits de |x| codé sur n bits</td><td class="num">−(2ⁿ⁻¹−1) … +(2ⁿ⁻¹−1)</td><td>deux zéros</td></tr>
<tr><td><b>Complément à 2</b> (vrai, Ca2)</td><td>Ca1 + 1</td><td class="num">−2ⁿ⁻¹ … +(2ⁿ⁻¹−1)</td><td>un seul zéro</td></tr></table></div>
<p>Les positifs s'écrivent pareil dans les 3 méthodes (bit de poids fort à 0). Sur 8 bits en Ca2 : de −128 à +127.</p>
<div class="def"><b>Deux méthodes pour le Ca2 (cours)</b>1. Ca2 = Ca1 + 1.<br>2. Parcourir depuis la droite : garder tous les bits jusqu'au premier 1 inclus, inverser tous les bits suivants. Exemple : 01000101 → 10111011 ; 01010100 → 10101100.</div>
<details class="ex"><summary>Exemple guidé : TD 1 ex. 4.1, coder −13 et −127 sur 8 bits</summary><div><div class="steps">|−13| = 13 = 00001101
S/VA : 10001101    Ca1 : 11110010    Ca2 : 11110011

|−127| = 127 = 01111111
S/VA : 11111111    Ca1 : 10000000    Ca2 : 10000001</div>
<div class="trap"><b>Piège du corrigé 2024</b>Il écrit « Complément à 1 de 10001101 = 11110010 » : il complémente le code S/VA en laissant le bit de signe. Le résultat est juste par coïncidence, mais la méthode du cours est d'inverser <b>|x| = 00001101</b>, bit de signe compris.</div></div></details>
<details class="ex"><summary>Exemple guidé : décoder 10010010 (TD 1 ex. 4.2)</summary><div><div class="steps">Non signé : 128 + 16 + 2 = 146
Signé, selon la convention :
  S/VA : signe 1, valeur 0010010 = 18      → −18
  Ca1  : on inverse → 01101101 = 109        → −109
  Ca2  : on prend le Ca2 → 01101110 = 110   → −110
Astuce Ca2 : valeur = −128×b7 + reste = −128 + 18 = −110</div>
<p>Le TD dit seulement « codage signé ». Le corrigé 2024 répond −110 (Ca2, la convention des machines). À l'examen, <b>écris la convention que tu utilises</b> ; si tu as le temps, donne les trois.</p></div></details>
<h4>Soustraire avec le Ca2</h4>
<p>a − b = a + Ca2(b). On fait l'addition binaire sur n bits et on <b>ignore la retenue qui sort</b> du bit de poids fort. Si le résultat commence par 1, il est négatif : on reprend son Ca2 pour lire sa valeur absolue.</p>
<div class="def"><b>Dépassement (overflow)</b>Il y a dépassement quand on additionne deux nombres de <b>même signe</b> et que le résultat a le <b>signe opposé</b>. Choisis donc n assez grand pour que a, b et le résultat tiennent dans −2ⁿ⁻¹ … 2ⁿ⁻¹−1.</div>
<details class="ex"><summary>Exemple guidé : 312 − 123 et 145 − 220 (TD 1 ex. 4.3)</summary><div><div class="steps">312 − 123 : 312 demande 9 bits en non signé, donc 10 bits en signé (max 511).
  312       = 0100111000
  123       = 0001111011 → Ca2 = 1110000101
  somme     = 1 0010111101 → on ignore la retenue → 0010111101 = 189 ✓

145 − 220 : 220 &gt; 127, on travaille sur 9 bits (−256 … 255).
  145       = 010010001
  220       = 011011100 → Ca2 = 100100100
  somme     = 110110101   (pas de retenue sortante, bit de signe 1 → négatif)
  Ca2(110110101) = 001001011 = 75 → résultat −75 ✓</div>
<div class="trap"><b>Pièges du corrigé 2024</b>Il fait 312 − 123 sur 9 bits : 312 ne tient pas en signé sur 9 bits (max 255), le résultat sort juste par chance. Pour 145 − 220, il code −220 sur 8 bits (impossible, min −128) et écrit une somme 100110101 fausse. Choisis toujours n d'abord et dis-le.</div></div></details>
```

{n6@15} Défauts du S/VA ? :: Deux représentations du zéro, et il faut deux circuits (addition et soustraction).
{n6@16} Méthode rapide du Ca2 ? :: Depuis la droite, garder les bits jusqu'au premier 1 inclus, inverser les suivants.
