```html
<div class="def"><b>Minterme et maxterme</b><b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">Minterme</b> : produit (ET) qui contient toutes les variables et vaut 1 pour une seule ligne. Ligne A=0 B=1 C=1 → Ā·B·C.<br>
<b style="display:inline;font:inherit;text-transform:none;letter-spacing:0">Maxterme</b> : somme (OU) qui contient toutes les variables et vaut 0 pour une seule ligne. Ligne A=0 B=0 C=1 → A + B + C̄ (on <b>complémente les variables qui valent 1</b>).</div>
<p><b>1re forme canonique</b> (disjonctive) = somme des mintermes des lignes où F = 1.<br><b>2e forme canonique</b> (conjonctive) = produit des maxtermes des lignes où F = 0.</p>
<div class="formula">Ligne   minterme (si F=1)   maxterme (si F=0)
A B C
0 0 0   Ā·B̄·C̄               A + B + C
0 0 1   Ā·B̄·C               A + B + C̄
0 1 0   Ā·B·C̄               A + B̄ + C
…       variable à 0 → barrée   variable à 1 → barrée</div>
<details class="ex"><summary>Exemple guidé : TD 2 ex. 2, G = A + B·C̄</summary><div><div class="steps">A B C | B·C̄ | G
0 0 0 |  0  | 0   → maxterme A+B+C
0 0 1 |  0  | 0   → maxterme A+B+C̄
0 1 0 |  1  | 1   → minterme Ā·B·C̄
0 1 1 |  0  | 0   → maxterme A+B̄+C̄
1 0 0 |  0  | 1   → A·B̄·C̄
1 0 1 |  0  | 1   → A·B̄·C
1 1 0 |  1  | 1   → A·B·C̄
1 1 1 |  0  | 1   → A·B·C
1re forme : G = Ā·B·C̄ + A·B̄·C̄ + A·B̄·C + A·B·C̄ + A·B·C        = Σm(2,4,5,6,7)
2e forme  : G = (A+B+C)·(A+B+C̄)·(A+B̄+C̄)                      = ΠM(0,1,3)</div>
<p>Autre méthode (diapo 29) : compléter chaque terme avec (X + X̄) pour faire apparaître les variables manquantes : A + B = A(B+B̄) + B(A+Ā) = AB + AB̄ + ĀB.</p></div></details>
<h4>Simplification algébrique : 3 techniques du cours</h4>
<ol><li><b>Regrouper</b> des termes adjacents : A·B·C + A·B·C̄ = A·B.</li>
<li><b>Rajouter un terme déjà présent</b> (A = A + A) pour faire plusieurs regroupements.</li>
<li><b>Supprimer un terme inclus</b> dans les autres (consensus) : A·B + B̄·C + A·C = A·B + B̄·C.</li></ol>
<details class="ex"><summary>Exemple guidé : TD 2 ex. 5, K = A·B̄·C + A·B·C̄ + Ā·B·C̄ + A·B·C</summary><div><div class="steps">A·B̄·C + A·B·C = A·C·(B̄ + B) = A·C
A·B·C̄ + Ā·B·C̄ = B·C̄·(A + Ā) = B·C̄
K = A·C + B·C̄
En NAND : K = ( (A·C)‾ · (B·C̄)‾ )‾ → 3 NAND à 2 entrées + 1 NAND pour faire C̄ = NAND(C,C)</div>
<div class="trap"><b>Piège du corrigé 2024</b>Il écrit K = A·C + B·C (barre perdue). Vérifie par la table : K(0,1,1) = 0, or B·C vaudrait 1.</div></div></details>
<details class="ex"><summary>Exemple guidé : TD 2 ex. 3, simplifier la 2e forme de H</summary><div><div class="steps">H vaut 0 aux lignes 000, 011, 111 :
H = (A+B+C)·(A+B̄+C̄)·(Ā+B̄+C̄)
(A+B̄+C̄)·(Ā+B̄+C̄) = B̄+C̄           (règle (X+Y)(X̄+Y) = Y)
H = (A+B+C)·(B̄+C̄) = A·B̄ + A·C̄ + B·C̄ + B̄·C   … (développement, B·B̄ = C·C̄ = 0)
  = B⊕C + A·C̄   (A·B̄ est inclus : consensus de B̄·C et A·C̄)
Forme équivalente minimale : B⊕C + A·B̄</div></div></details>
```
