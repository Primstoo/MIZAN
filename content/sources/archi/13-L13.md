```html
<p>Le <b>langage machine</b> est binaire : une instruction = un <b>opcode</b> (nature de l'opération) suivi des opérandes (ex. AB 00 02). L'<b>assembleur</b> en est la représentation symbolique lisible : MOV, ADD, DIV…</p>
<h4>Variables, constantes, tableaux, chaînes</h4>
<div class="formula">var1 DB 56d          ; Define Byte : 1 octet (décimal)
var2 DB ?            ; non initialisée
var3 DW 1210h        ; Define Word : 2 octets      DD : 4 octets
B4   DB 0FFh         ; un nombre hexa qui commence par une lettre prend un 0 devant
B5   DB 1010b        ; binaire
K    EQU 50h         ; constante : remplacée par sa valeur à l'assemblage
tab  DB 01h,02h,03h  ; tableau ; tab[1] = 02h
t2   DB 5 DUP(1,2)   ; répète (1,2) 5 fois → 10 octets
msg  DB 'HELLO$'     ; chaîne terminée par $
MOV AX, SEG var1     ; adresse de segment      MOV BX, OFFSET var1 ; déplacement</div>
<details class="ex"><summary>Exemple guidé : TP 3 ex. 4</summary><div><div class="steps">B0 DB 1        B1 DB 8      B2 DB 17     B3 DB 32h
B4 DB 0FFh     B5 DB 1b     B6 DB 1010b
D0 DW 1  …  D6 DW 7                         ; valeurs au choix
TabB DB 1, 8, 17, 32h, 0FFh, 1b, 1010b
TabD DW 1, 2, 3, 4, 5, 6, 7
T1 DB 152 DUP(101)
T2 DW 150 DUP(0BAC2h)</div>
<div class="trap"><b>Pièges du corrigé 2024</b>Il écrit <code>TabB DB B0, B1, …</code> : on ne peut pas initialiser un DB avec des noms de variables (ce serait leurs adresses, et ça ne tient pas sur un octet). Et il met <code>152 DUP(8)</code> et <code>0BAC3h</code> au lieu de 101 et BAC2h.</div></div></details>
<h4>Modes d'adressage (où se trouve l'opérande ?)</h4>
<div class="table-wrap"><table><tr><th>Mode</th><th>Exemple</th><th>L'opérande est…</th></tr>
<tr><td>Immédiat</td><td class="num">MOV AH, 12h</td><td>dans l'instruction (constante)</td></tr>
<tr><td>Registre</td><td class="num">MOV AX, BX · INC AX</td><td>dans un registre</td></tr>
<tr><td>Direct</td><td class="num">MOV AX, [243]</td><td>en mémoire, offset écrit dans l'instruction (DS par défaut)</td></tr>
<tr><td>Indirect (basé)</td><td class="num">MOV AX, [BX] · [BX+3] · [BP−100]</td><td>en mémoire, offset dans BX (DS) ou BP (SS), + déplacement éventuel</td></tr>
<tr><td>Indirect (indexé)</td><td class="num">MOV AX, [SI+200] · [DI−7]</td><td>offset dans SI ou DI (DS)</td></tr>
<tr><td>Basé indexé</td><td class="num">MOV AX, [BX+DI+7] · [BP+SI−3]</td><td>base + index + déplacement (segment par défaut du registre de base)</td></tr></table></div>
<p>Pour une instruction à deux opérandes, on nomme le mode d'après l'opérande <b>source</b> en général ; dans <code>MOV [1100h], AL</code> le mode est direct (la destination est en mémoire). Dis-le dans ta réponse.</p>
<h4>Transfert</h4>
<div class="formula">MOV dest, source   ; dest ← source (même taille !)
Autorisés : reg ← reg, mém ← reg, reg ← mém, reg ← constante, mém ← constante, seg ← reg général
Interdits  : mém ← mém, seg ← constante, deux tailles différentes (MOV AX, BL)
XCHG a, b          ; échange (reg/reg, reg/mém)</div>
<h4>Arithmétique</h4>
<div class="formula">ADD d, s  ; d ← d + s          SUB d, s ; d ← d − s
INC d     ; d ← d + 1          DEC d    ; d ← d − 1      (INC/DEC ne touchent pas CF)
MUL s  (non signé)  8 bits : AX ← AL × s          16 bits : DX:AX ← AX × s
DIV s  (non signé)  8 bits : AL ← AX ÷ s, AH ← reste
                   16 bits : AX ← DX:AX ÷ s, DX ← reste
Exemples du cours : AL=200, BL=4, MUL BL → AX = 0320h (800)
                    AX=203, BL=4, DIV BL → AL = 50 (32h), AH = 3</div>
<details class="ex"><summary>Exemple guidé : TP 3 ex. 2 (registres au départ à 0)</summary><div><div class="steps">MOV AX, 1008h   ; AX = 1008h
MOV BH, 05h     ; BX = 0500h (BL = 00)
SUB AX, BX      ; AX = 1008h − 0500h = 0B08h
SUB AH, 02h     ; AH = 0Bh − 02h = 09h → AX = 0908h
MUL BH          ; AX = AL × BH = 08h × 05h = 28h → AX = 0028h</div></div></details>
<details class="ex"><summary>Exemple guidé : TP 4 ex. 2 (MUL et drapeaux)</summary><div><div class="steps">MOV AL,64h ; MOV BL,2 ; MUL BL   → AX = 100 × 2 = 200 = 00C8h, AH = 0 → CF = OF = 0
MOV AL,64h ; MOV CL,3 ; MUL CL   → AX = 300 = 012Ch, AH ≠ 0 → CF = OF = 1
Règle : après MUL, CF = OF = 1 si la moitié haute du résultat (AH ou DX) n'est pas nulle.</div></div></details>
<details class="ex"><summary>Exemple guidé : TP 4 ex. 3, A = 10110000, B = 10111100 (signés)</summary><div><div class="steps">A = B0h = −80 ; B = BCh = −68
A + B : B0h + BCh = 16Ch → AL = 6Ch, retenue sortante
        CF = 1, ZF = 0, SF = 0, OF = 1 (négatif + négatif = positif : dépassement, −148 &lt; −128)
A − B : B0h − BCh = F4h (−12), il faut emprunter
        CF = 1, ZF = 0, SF = 1, OF = 0</div></div></details>
<details class="ex"><summary>Exemple guidé : TD 4 ex. 6 / TP 4 ex. 1, sommes de variables</summary><div><div class="steps">.data
A DB 5      B DB 7      C DW 300     D DW 450
.code
MOV AL, A     ; octets → registre 8 bits
ADD AL, B
MOV A, AL
MOV AX, C     ; mots → registre 16 bits
ADD AX, D
MOV C, AX</div>
<div class="trap"><b>Piège du corrigé 2024</b>Il écrit <code>MOV AX, A</code> avec A en DB : erreur de taille (16 bits ← 8 bits), l'assembleur refuse.</div></div></details>
```
