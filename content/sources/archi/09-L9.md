```html
<div class="def"><b>Combinatoire</b>Les sorties ne dépendent <b>que des entrées présentes</b>. Pas de mémoire, pas de rebouclage d'une sortie vers une entrée.</div>
<h4>Additionneur complet (1 bit)</h4>
<div class="formula">Entrées a, b, R (retenue entrante) ; sorties S (somme), R' (retenue sortante)
S  = a ⊕ b ⊕ R
R' = a·b + (a ⊕ b)·R
Additionneur n bits : chaîner n additionneurs, R' du rang i → R du rang i+1, R₀ = 0.
Demi-additionneur (sans retenue entrante) : S = a ⊕ b, C = a·b</div>
<h4>Décodeur n → 2ⁿ</h4>
<p>n entrées, 2ⁿ sorties, <b>une seule sortie active</b> à la fois : celle dont le numéro est écrit sur les entrées. Avec une entrée de validation V : décodeur 2→4, S₀ = Ā·B̄·V, S₁ = Ā·B·V, S₂ = A·B̄·V, S₃ = A·B·V.</p>
<h4>Codeur 2ⁿ → n (TP 1)</h4>
<p>Inverse du décodeur : une seule entrée active, la sortie donne son numéro en binaire. Codeur 4→2 : S₁ = E₂ + E₃, S₀ = E₁ + E₃ (2 portes OU, aucune porte ET ni NON après simplification de Karnaugh avec les combinaisons interdites en X).</p>
<h4>Multiplexeur 2ⁿ → 1</h4>
<p>2ⁿ entrées d'information, n entrées de sélection (commandes), <b>une sortie</b> qui recopie l'entrée choisie. MUX 4→1 : S = C̄₁·C̄₀·E₀ + C̄₁·C₀·E₁ + C₁·C̄₀·E₂ + C₁·C₀·E₃.</p>
<div class="def"><b>Réaliser une fonction de n variables avec un MUX 2ⁿ → 1</b>On branche les variables sur les commandes, et sur chaque entrée Eᵢ on met la valeur de F à la ligne i de la table : 0 (masse) ou 1 (Vcc). Attention à l'ordre des variables sur les commandes (poids fort / poids faible).</div>
<h4>Démultiplexeur 1 → 2ⁿ</h4>
<p>Une entrée I, n commandes, 2ⁿ sorties : I est envoyée sur la sortie choisie, les autres restent à 0. DEMUX 1→4 : S₀ = C̄₁·C̄₀·I … S₃ = C₁·C₀·I.</p>
<div class="def"><b>Réaliser une fonction avec un DEMUX</b>On met I = 1 et les variables sur les commandes. La sortie Sᵢ vaut 1 seulement pour la combinaison i : c'est le minterme i. Donc F = <b>OU des sorties Sᵢ pour lesquelles F = 1</b> (diapo 14 : S = S₀ + S₁ + S₂).</div>
<details class="ex"><summary>Exemple guidé : TD 3 ex. 3, parité de 3 bits</summary><div><div class="steps">Sortie 1 si le nombre de 1 est IMPAIR (énoncé : 011 → 0, 100 → 1) : F = a ⊕ b ⊕ c
abc : 000 001 010 011 100 101 110 111
F   :  0   1   1   0   1   0   0   1
MUX 8→1 (commandes a b c) : E1 = E2 = E4 = E7 = 1 (Vcc), E0 = E3 = E5 = E6 = 0 (masse)
DEMUX 1→8 (I = 1) : F = S1 + S2 + S4 + S7 (une porte OU à 4 entrées)</div>
<div class="trap"><b>Piège du corrigé 2024</b>Sa table de vérité est inversée (il met F = 1 pour 000). Relis l'énoncé : 0 si pair, 1 si impair.</div></div></details>
<details class="ex"><summary>Exemple guidé : TD 3 ex. 2, complément à 2 sur 3 bits avec 3 MUX 8→1</summary><div><div class="steps">Ca2(n) = (8 − n) mod 8
abc  : 000 001 010 011 100 101 110 111
Ca2  : 000 111 110 101 100 011 010 001
S2 (poids fort) : 0 1 1 1 1 0 0 0   → MUX n°1 : E1..E4 = 1, autres 0
S1              : 0 1 1 0 0 1 1 0   → MUX n°2 : E1 E2 E5 E6 = 1
S0              : 0 1 0 1 0 1 0 1   → MUX n°3 : E1 E3 E5 E7 = 1 (S0 = c)
Les 3 MUX ont les mêmes commandes a, b, c.</div></div></details>
```
