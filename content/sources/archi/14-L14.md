```html
<p class="small muted">Les diapos de cette partie (« jeu d'instructions » suite) n'étaient pas dans ton archive. Ce qui suit est le comportement standard du 8086, celui de emu8086 utilisé en TP.</p>
<h4>Instructions logiques (bit à bit)</h4>
<div class="formula">AND d, s ; ET bit à bit (sert à forcer des bits à 0 : masque)     → CF = OF = 0
OR  d, s ; OU bit à bit (forcer des bits à 1)
XOR d, s ; OU exclusif (XOR AX, AX met AX à 0)
NOT d    ; complément à 1           NEG d ; complément à 2 (d ← −d)
Exemple TP 3 ex. 3 : AL = DFh ; AND AL,11011111b → DFh ; INC AL → E0h
                     AH = CCh ; OR AH,20h → ECh ; DEC AH → EBh</div>
<h4>Décalages et rotations</h4>
<div class="formula">SHL d, n ; décalage à gauche, entre des 0 à droite, le bit sorti va dans CF  → × 2ⁿ (non signé)
SHR d, n ; décalage à droite, entre des 0 à gauche, bit sorti dans CF        → ÷ 2ⁿ (quotient)
ROL d, n ; rotation à gauche : le bit qui sort à gauche rentre à droite (et dans CF)
ROR d, n ; rotation à droite
Sur le 8086, n vaut 1 ou CL :  MOV CL, 3 ; SHR AL, CL
(emu8086 accepte aussi une constante comme SHL AX, 8)</div>
<details class="ex"><summary>Exemple guidé : TD 5 ex. 1</summary><div><div class="steps">MOV AX, 0      ; AX = 0000h
INC AX         ; AX = 0001h
MOV BX, AX     ; BX = 0001h
SHL AX, 8      ; AX = 0100h   (× 256)
ADD AH, BL     ; AH = 01h + 01h = 02h → AX = 0200h
MOV BH, BL     ; BH = 01h → BX = 0101h
MOV DX, AX     ; DX = 0200h
SUB AX, BX     ; AX = 0200h − 0101h = 00FFh
AND DX, BX     ; DX = 0200h AND 0101h = 0000h
XOR AX, AX     ; AX = 0000h
2. INC AX ⇔ ADD AX, 1
3. SHL CX,1 : CX = 1010h → 2020h ; CX = 1336h → 266Ch (× 2, CF = 0 dans les deux cas)
4. SHL AX,V1 et ROL AX,V2 donnent le même AX si V1 = V2 (mod 16) et si les V1 bits de poids
   fort de AX valent 0 (ROL les ferait revenir à droite, SHL fait entrer des 0).</div></div></details>
<h4>Comparaison et sauts</h4>
<div class="formula">CMP a, b   ; calcule a − b sans rien stocker, positionne les drapeaux
JMP etiq   ; saut inconditionnel
JE / JZ    ; saut si égal (ZF=1)          JNE / JNZ ; si différent (ZF=0)
Non signés : JA (a&gt;b)  JAE  JB (a&lt;b)  JBE
Signés     : JG (a&gt;b)  JGE  JL (a&lt;b)  JLE      JS : si négatif (SF=1)   JC : si CF=1</div>
<h4>Boucles</h4>
<div class="formula">LOOP etiq  ; CX ← CX − 1 ; si CX ≠ 0, saute à etiq   → on met d'abord le nombre de tours dans CX</div>
<details class="ex"><summary>Exemple guidé : TD 5 ex. 4 / TP 5 ex. 4, somme 0 + 1 + … + 11</summary><div><div class="steps">.data
R DW ?
N DW 11
.code
; Méthode 1 : MOV, CMP, JNE, ADD, INC
    MOV AX, 0        ; somme
    MOV BX, 0        ; compteur i
boucle1:
    INC BX           ; i = 1, 2, …, 11
    ADD AX, BX
    CMP BX, N
    JNE boucle1
    MOV R, AX        ; R = 66

; Méthode 2 : LOOP (CX descend de 11 à 1)
    MOV AX, 0
    MOV CX, N
boucle2:
    ADD AX, CX       ; 11 + 10 + … + 1
    LOOP boucle2
    MOV R, AX        ; R = 66</div>
<div class="trap"><b>Pièges du corrigé 2024</b>Il n'initialise pas AX (valeur inconnue au départ), n'utilise pas N, et met JA au lieu du JNE demandé. Respecte les instructions imposées par l'énoncé : elles sont notées.</div></div></details>
<h4>Pile</h4>
<div class="formula">PUSH s  ; SP ← SP − 2 ; [SS:SP] ← s      (16 bits uniquement)
POP d   ; d ← [SS:SP] ; SP ← SP + 2
La pile est LIFO : le dernier empilé est le premier dépilé.
TP 4 ex. 4 : PUSH AX ; PUSH BX ; POP AX ; POP BX → AX et BX sont échangés (AX = 5678h, BX = 1234h)
Équivalent de PUSH AX : SUB SP, 2 ; MOV BP, SP ; MOV [BP], AX     ([SP] n'est pas un adressage valide)
Équivalent de POP AX  : MOV BP, SP ; MOV AX, [BP] ; ADD SP, 2</div>
<h4>Traduire if / for / while / switch (TP 5)</h4>
<div class="formula">; for (CX=0; CX&lt;BX; CX++) BX = BX + CX;      avec BX = 10 au départ
    MOV BX, 10
    MOV CX, 0
pour: CMP CX, BX
    JGE finpour        ; (JAE en non signé)
    ADD BX, CX
    INC CX
    JMP pour
finpour:
; ⚠ BX grandit à chaque tour : la boucle ne s'arrête qu'au dépassement de BX (piège voulu de l'énoncé)

; while (BX &gt; 0) BX = BX − 1;   avec BX = 0 → on n'entre jamais dans la boucle
tq: CMP BX, 0
    JLE fintq
    DEC BX
    JMP tq
fintq:

; switch (BX)
    CMP BX, 1
    JE cas1
    CMP BX, 2
    JE cas2
    CMP BX, 3
    JE cas3
    MOV AX, 0          ; default
    JMP finsw
cas1: MOV AX, 1
    JMP finsw
cas2: MOV AX, 5
    JMP finsw
cas3: MOV AX, 10
finsw:</div>
<details class="ex"><summary>Exemple guidé : TP 5 ex. 2, ranger une somme signée selon son signe</summary><div><div class="steps">    MOV AL, [1100h]
    ADD AL, [1101h]
    JZ  nul            ; résultat = 0
    JS  negatif        ; SF = 1
    MOV [1103h], AL    ; positif
    JMP fin
negatif: MOV [1102h], AL
    JMP fin
nul: MOV [1104h], AL
fin:</div></div></details>
<h4>Entrées/sorties avec INT 21h (TP 5 ex. 3)</h4>
<div class="formula">.data
m1 DB 'Saisir un caractere: $'
m2 DB 13,10,'Le caractere saisi est: $'
.code
    MOV AX, @data
    MOV DS, AX
    MOV AH, 09h        ; afficher la chaîne DS:DX terminée par $
    LEA DX, m1
    INT 21h
    MOV AH, 01h        ; lire un caractère → AL
    INT 21h
    MOV BL, AL
    MOV AH, 09h
    LEA DX, m2
    INT 21h
    MOV AH, 02h        ; afficher le caractère contenu dans DL
    MOV DL, BL
    INT 21h
    MOV AH, 4Ch        ; fin du programme
    INT 21h</div>
<details class="ex"><summary>Exemple guidé : TD 5 ex. 2 et 3</summary><div><div class="steps">; Diviser par 8 l'octet en 0140h, résultat en 0141h
MOV AL, [0140h]
MOV CL, 3
SHR AL, CL
MOV [0141h], AL

; a × 2^p, a en 140h, p en 142h, résultat en 144h
MOV AX, [140h]
MOV CL, [142h]
SHL AX, CL
MOV [144h], AX

; r = x × y (16 bits), x en 30h, y en 32h : le produit fait 32 bits !
MOV AX, [30h]
MUL WORD PTR [32h]   ; DX:AX = x × y
MOV [34h], AX        ; poids faible
MOV [36h], DX        ; poids fort

; x ÷ y, x sur 16 bits (30h), y sur 8 bits (32h)
MOV AX, [30h]
DIV BYTE PTR [32h]   ; AL = quotient, AH = reste (le quotient doit tenir sur 8 bits)
MOV [34h], AL
MOV [35h], AH</div>
<div class="trap"><b>Piège du corrigé 2024</b>Pour r = x × y il ne range que AX : il perd les 16 bits de poids fort (DX).</div></div></details>
```
