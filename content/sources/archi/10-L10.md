```html
<div class="def"><b>Séquentiel</b>Les sorties dépendent des entrées <b>et de l'état précédent</b> des sorties (entrées secondaires) : le circuit a une <b>mémoire</b>. On le reconnaît à un <b>rebouclage</b> d'une sortie vers une entrée. Notations : Qn état présent, Qn+1 état suivant.</div>
<p><b>Asynchrone</b> : les sorties changent dès que les entrées changent. <b>Synchrone</b> : elles changent seulement au signal d'<b>horloge</b> H (CLK), sur un front montant ↑ ou descendant ↓.</p>
<details class="ex"><summary>Exemple guidé : TD 3 ex. 1</summary><div>
<p>Le circuit est <b>séquentiel</b> : la sortie S revient en entrée (rebouclage), donc la sortie dépend de son état précédent.</p>
<div class="steps">Portes : P = E1·E2 ; Q = E1 + E2 ; l'inverseur reçoit Sn
F    = E1·E2 + (E1 + E2)·S̄n
Sn+1 = E1·E2 + (E1 + E2)·Sn       (= fonction majorité de E1, E2, Sn)</div>
<p>Vérifie le sens de chaque fil : l'inverseur va vers la porte ET du <b>haut</b>, donc F utilise S̄n. Le corrigé 2024 a perdu la barre.</p></div></details>
<h4>Bascule RS (asynchrone)</h4>
<div class="formula">S R | Qn+1
0 0 | Qn     mémorisation
0 1 | 0      Reset (mise à 0)
1 0 | 1      Set (mise à 1)
1 1 | interdit   (les diapos écrivent 0 dans la case, mais marquent « Interdit »)</div>
<h4>Bascule RSH (RS synchronisée)</h4>
<p>Même table, mais prise en compte seulement sur le front d'horloge. Hors front : Qn+1 = Qn.</p>
<h4>Bascule JK</h4>
<div class="formula">CLK J K | Q
 X  X X | Qn−1     mémoire (pas de front)
 ↑  0 0 | Qn−1     mémoire
 ↑  0 1 | 0        mise à 0
 ↑  1 0 | 1        mise à 1
 ↑  1 1 | Q̄n−1     basculement (état complémenté)
Équation : Qn+1 = J·Q̄n + K̄·Qn</div>
<div class="exam"><b>Chronogramme</b>Pour tracer Q : repère chaque front actif, lis J et K juste avant ce front, applique la table, et garde Q constant jusqu'au front suivant. Q̄ est toujours l'inverse de Q. L'atelier « Bascules » entraîne exactement ça.</div>
<h4>Registres</h4>
<p>Association de n bascules qui mémorise un mot de n bits ; toutes les horloges sont reliées ; entrée « Load » : sur un front, les entrées sont recopiées sur les sorties.</p>
<ul><li><b>PIPO</b> entrées parallèles / sorties parallèles · <b>PISO</b> parallèle → série · <b>SIPO</b> série → parallèle · <b>SISO</b> série → série.</li>
<li><b>Registre à décalage</b> (SISO) : à droite, la bascule de rang i recopie la sortie du rang i−1 ; à gauche, celle du rang i+1.</li></ul>
```

## Questions de rédaction

```exercice
? {n16} Différence entre circuit combinatoire et circuit séquentiel ?
= Combinatoire : les sorties ne dépendent que des entrées présentes. Séquentiel : les sorties dépendent aussi de l'état précédent des sorties ; le circuit a une mémoire, souvent visible par un rebouclage d'une sortie vers une entrée.
```

## Flashcards

```cartes
{n16@39} Combinatoire vs séquentiel ? :: Combinatoire : sorties = f(entrées présentes).<br>Séquentiel : sorties = f(entrées, état précédent) → mémoire, rebouclage.
{n16@40} Synchrone vs asynchrone ? :: Asynchrone : réagit dès que les entrées changent.<br>Synchrone : réagit seulement au signal d'horloge (front montant ou descendant).
{n16@41} Table de la bascule RS ? :: 00 : mémoire ; 01 : Q = 0 ; 10 : Q = 1 ; 11 : interdit.
{n16@42} Table de la bascule JK ? :: 00 : mémoire ; 01 : 0 ; 10 : 1 ; 11 : basculement (Q̄).<br>Qn+1 = J·Q̄n + K̄·Qn
{n17@43} PIPO, PISO, SIPO, SISO ? :: Entrées/sorties parallèles ou série. Le registre à décalage est un SISO.
```
