## Session normale · exercice 1 (lentille biconcave épaisse)

**Énoncé.** Lentille biconcave en verre (n = 3/2) dans l'air : $\overline{S_1C_1} = -R$, $\overline{S_2C_2} = R$, $\overline{S_1S_2} = R$, R = 7 cm.

```exercice Partie A
? A-1, 2) Nature des dioptres et distances focales.
= Deux dioptres concaves (divergents). D₁ (air → verre) : $f_1' = \frac{n\overline{S_1C_1}}{n-1} = -3R = -21$ cm, $f_1 = 2R = 14$ cm. D₂ (verre → air) : $f_2' = \frac{\overline{S_2C_2}}{1-n} = -2R = -14$ cm, $f_2 = 3R = 21$ cm.

? A-4, 5) Vergence (Gullstrand), f' et nature.
= $V_1 = V_2 = -\frac{0{,}5}{R}$. $V = V_1 + V_2 - \frac{R}{n}V_1V_2 = -\frac1R - \frac{1}{6R} = -\frac{7}{6R} \approx -16{,}7$ δ. Donc **f' = −6 cm**, f = +6 cm : système **divergent**.
reponse: -6

? A-6) Position des foyers.
= $\overline{S_2F'} = f'\left(1 - \frac{e}{n}V_1\right) = -6\times\frac43 = -8$ cm. Par symétrie, $\overline{S_1F} = +8$ cm. (Vérifié par calcul matriciel.)
reponse: -8
```

Partie B (face de sortie métallisée) : on obtient un **système catadioptrique**, équivalent à un **miroir sphérique** unique. Son centre Ω est l'image de C₂ à travers D₁, son sommet Σ l'image de S₂ à travers D₁. Méthode : applique deux fois la conjugaison de D₁.

## Session normale · exercice 2 (système grossissant)

**Énoncé.** L₁ : f'₁ = 3 cm ; L₂ : f'₂ = −6 cm ; $\overline{O_1O_2} = 9$ cm. Œil normal (PP = 25 cm), observation sans fatigue.

```exercice Exercice 2
? Position de l'image intermédiaire A₁ et de l'objet.
= Image finale à l'infini : A₁ au foyer objet de L₂, $\overline{O_2F_2} = +6$ cm, donc $\overline{O_1A_1} = 15$ cm. Conjugaison L₁ : $\frac{1}{\overline{O_1A}} = \frac{1}{15} - \frac13 = -\frac{4}{15}$, donc **$\overline{O_1A} = -3{,}75$ cm**.
reponse: -3.75

? Grossissement G.
= $\gamma_1 = 15/(-3{,}75) = -4$. α = AB/25 ; α' = |A₁B₁|/6 = 4AB/6. **|G| = (4/6) × 25 ≈ 16,7** (image renversée).
reponse: 16.7
```

## Session normale · exercice 3 (sodium 24)

```exercice Exercice 3
? Équation et λ.
= ${}^{24}_{11}\text{Na} \to {}^{24}_{12}\text{Mg} + {}^{0}_{-1}e$ (β⁻). λ = ln 2 / 15 h ≈ 0,0462 h⁻¹ ≈ 1,28·10⁻⁵ s⁻¹.

? n₁ à t₁ = 3 h.
= $n_0 = C_0V_0 = 10^{-3}\times5\cdot10^{-3} = 5\cdot10^{-6}$ mol. $n_1 = n_0\,2^{-3/15} \approx 4{,}35\cdot10^{-6}$ mol.

? Volume de sang perdu.
= Concentration mesurée : $2{,}1\cdot10^{-9} / 2\cdot10^{-3} = 1{,}05\cdot10^{-6}$ mol/L. Volume restant : $4{,}35\cdot10^{-6}/1{,}05\cdot10^{-6} \approx 4{,}15$ L. **Vp ≈ 5 − 4,15 ≈ 0,85 L.**
reponse: 0.85
```

Exercices 2 et 3 du rattrapage (dioptre + dioptre plan, miroir + lame) : les figures et les signes des rayons sont illisibles dans le fichier. Méthode : enchaîne les conjugaisons, objet de chaque élément = image du précédent. Pour une lame d'épaisseur e et d'indice n, le déplacement apparent vaut $e\left(1 - \frac1n\right)$, résultat à démontrer dans le sujet.
