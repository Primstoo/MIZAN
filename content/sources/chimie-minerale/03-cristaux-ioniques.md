## Avant de commencer

Il faut savoir que, dans un cristal ionique, un cation est entouré d'anions et réciproquement.

```exercice Vérifie ton prérequis
? Dans NaCl, combien de Cl⁻ entourent un Na⁺ ?
= 6 (coordinence octaédrique).
reponse: 6
```

## Comment aborder ce chapitre

> [!astuce] **Pense « les anions font l'empilement, les cations remplissent les trous ».** Le rapport des rayons $r^+/r^-$ dit quel trou le cation peut occuper.

> [!piege] Oublier de vérifier la neutralité. Dans la maille, le nombre de charges + doit égaler le nombre de charges −.

À la fin, tu sais identifier la structure d'un composé AB à partir de Z et du rapport des rayons.

## Idée 1 · Les quatre structures à connaître

```grille Structures types
#cols: Type, Réseau, Coordinence, Z (motifs AB), Contact anion-cation
*CsCl, cubique P, 8-8, 1, a√3/2 = r⁺ + r⁻
*NaCl, cubique F, 6-6, 4, a/2 = r⁺ + r⁻
*ZnS blende, cubique F, 4-4, 4, a√3/4 = r⁺ + r⁻
*CaF₂ fluorine, cubique F, 8-4, 4 (CaF₂), a√3/4 = r⁺ + r⁻
```

```etapes Identifier une structure AB
1. Calcule Z = ρ·a³·N_A / M.
2. Z = 1 : CsCl. Z = 4 : NaCl ou ZnS.
3. Pour départager : rapport r⁺/r⁻, ou relation de contact avec les rayons connus.
```

## Idée 3 · Masse volumique d'un cristal ionique

**Exemple (NaCl).** a = 564 pm, M = 58,44 g/mol, Z = 4 : $\rho = \frac{4\times58{,}44}{6{,}02\cdot10^{23}\times(5{,}64\cdot10^{-8})^3} \approx 2{,}16$ g/cm³.

## S'exercer

```exercice Application
? Composé AB : a = 398 pm, ρ = 2,10 g/cm³, M = 79,9 g/mol. Z ?
= $Z = \frac{2{,}10\times(3{,}98\cdot10^{-8})^3\times6{,}02\cdot10^{23}}{79{,}9} \approx 1{,}0$ : **type CsCl**.
reponse: 1

? Rapport $r^+/r^- = 0{,}5$ : quelle coordinence attendue ?
= Entre 0,414 et 0,732 : coordinence 6, type NaCl.
reponse: 6
```

## Flashcards

```cartes
CsCl :: Cubique P, 8-8, Z = 1, contact sur la grande diagonale.
NaCl :: Cubique F, 6-6, Z = 4, contact sur l'arête : a = 2(r⁺ + r⁻).
Blende ZnS :: Cubique F, 4-4, Z = 4, Zn dans la moitié des sites tétraédriques.
Seuils de r⁺/r⁻ :: 0,225 ; 0,414 ; 0,732.
```

## QCM du chapitre

```qcm

+ 8-8

- 4-4

- 1

+ a = 2(r⁺ + r⁻)

? r⁺/r⁻ = 0,8 favorise :
+ CsCl
- NaCl
- ZnS
= Au-dessus de 0,732.

? Dans la fluorine CaF₂, F⁻ est en coordinence :
+ 4
- 8
- 6
= Ca²⁺ en coordinence 8.

? Le réseau de NaCl est :
- cubique P
+ cubique F
- cubique I
= Deux sous-réseaux F imbriqués.

? Z = 1 avec un composé AB indique :
+ CsCl
- NaCl
- ZnS
= Seule structure à 1 motif.

? Une maille doit être :
+ électriquement neutre
- chargée positivement
- vide au centre
= Neutralité.

? CsCl n'est pas un cubique centré parce que :
+ le nœud du centre porte un ion différent
- il n'a pas d'ion au centre
- il est hexagonal
= Réseau P avec un motif de deux ions.
```
