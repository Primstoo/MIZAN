## Comment aborder ce chapitre

> [!astuce] **Une fonction = une formule du cours.** César, c'est (x + k) mod 26 ; Vigenère, c'est la même chose avec un k qui change à chaque lettre. Écris d'abord la formule, le code suit.

> [!piege] Oublier de garder les espaces et la ponctuation intacts, ou faire avancer l'indice de la clé de Vigenère sur un espace. Seules les lettres consomment la clé.

> [!prof] Le prof aime ramener le TP à l'examen : chiffrer à la main un mot court, retrouver une clé de César à partir de la lettre la plus fréquente, écrire la formule de déchiffrement. Les trois sont ci-dessous.

À la fin, tu sais coder les deux chiffres, les déchiffrer, et casser César par les fréquences.

## Exercice 1 · César

Chiffrer : C = (P + k) mod 26. Déchiffrer : P = (C − k) mod 26, donc déchiffrer = chiffrer avec −k.

```python
A = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
def cesar(m, k):
    return "".join(A[(A.index(c) + k) % 26] if c in A else c for c in m.upper())
c = cesar("Bonjour le monde", 3)
print(c)
print(cesar(c, -3))
```

```sortie
ERQMRXU OH PRQGH
BONJOUR LE MONDE
```

## Exercice 2 · Vigenère

La clé est répétée sous le message ; chaque lettre est décalée du rang de la lettre de clé (A = 0). Déchiffrer : même fonction avec le signe −.

```python
A = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
def vig(m, cle, sens=1):
    r, i = "", 0
    for c in m.upper():
        if c in A:
            r += A[(A.index(c) + sens * A.index(cle[i % len(cle)])) % 26]
            i += 1
        else:
            r += c
    return r
c = vig("Attaquez a l aube", "CLE")
print(c)
print(vig(c, "CLE", -1))
```

```sortie
CEXCBYGK E N LYDP
ATTAQUEZ A L AUBE
```

> [!retenir] À la main : A + C = C, T + L = E, T + E = X. L'espace ne consomme pas de lettre de clé.

## Exercice 3 · Casser César par les fréquences

```etapes
Compter chaque lettre du texte chiffré.
Prendre la plus fréquente : elle correspond (probablement) à E.
Clé k = (rang de cette lettre − 4) mod 26.
Déchiffrer avec −k et vérifier que le texte a un sens.
```

```python
from collections import Counter
A = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
def cesar(m, k):
    return "".join(A[(A.index(c) + k) % 26] if c in A else c for c in m.upper())
clair = "le chiffre de cesar decale chaque lettre et reste simple a casser car la lettre e reste la plus frequente"
chiffre = cesar(clair, 11)
lettre = Counter(c for c in chiffre if c in A).most_common(1)[0][0]
k = (A.index(lettre) - 4) % 26
print(lettre, k)
print(cesar(chiffre, -k))
```

```sortie
P 11
LE CHIFFRE DE CESAR DECALE CHAQUE LETTRE ET RESTE SIMPLE A CASSER CAR LA LETTRE E RESTE LA PLUS FREQUENTE
```

> [!attention] Sur un texte court, la lettre la plus fréquente n'est pas toujours E. Si le résultat n'a pas de sens, essaie la 2e lettre la plus fréquente (puis A, S…).
