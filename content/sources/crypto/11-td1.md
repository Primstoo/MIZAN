## Flashcards

```cartes
{td1@81} Substitution par alphabet-clé : principe ? :: La clé est un alphabet complet mélangé : sa 1re lettre remplace A, la 2e remplace B, etc. 26! clés, mais les fréquences la cassent.
{td1@82} Protocole XOR à trois passes : pourquoi est-il cassé ? :: C₁ ⊕ C₂ = L donne la clé de Bob, puis C₃ ⊕ L = M. Ou directement C₁ ⊕ C₂ ⊕ C₃ = M. Le XOR est linéaire.
{td1@83} Les 3 règles du XOR pour rédiger une démonstration ? :: K ⊕ K = 0 ; X ⊕ 0 = X ; il est commutatif et associatif.
{td1@84} Clé inverse de Vigenère pour SECURITE ? :: IWYGJSHW. Le corrigé manuscrit qui circule écrit F au lieu de H : c'est faux, T = 19 donne 26 − 19 = 7 = H.
{td1@85} Substitution et transposition, en une phrase ? :: La substitution change les lettres mais garde leur position ; la transposition garde les lettres mais change leur position.
```

= K\[1\]=2 → K⁻¹\[2\]=1 ; K\[2\]=3 → K⁻¹\[3\]=2 ; K\[3\]=1 → K⁻¹\[1\]=3. Donc \[3,1,2\].

? {lfsr} Clé inverse de Vigenère de la lettre A.

= −0 mod 26 = 0 = A.
