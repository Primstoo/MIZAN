## Flashcards

```cartes
{n14@28} Topologie logique vs physique ? :: Logique : périphériques, ports et schéma d'adressage IP.<br>Physique : emplacement physique des périphériques, des ports configurés et des câbles.
{n15@29} Les 6 topologies physiques du cours ? :: Bus, anneau, étoile, étoile étendue, maillée (mesh), hiérarchique.
{n15@30} Bus : support, avantage, inconvénient ? :: Toutes les machines sont sur une même ligne (souvent du câble coaxial).<br>+ Simple, facile à mettre en œuvre.<br>− Si le câble commun se rompt, tout le réseau tombe.
{n15@31} Anneau : fonctionnement + FDDI ? :: Hôtes chaînés en boucle, données passées au voisin dans un seul sens ; un jeton circule (Token Ring).<br>FDDI = double anneau : le second anneau assure la tolérance aux pannes du premier.
{n15@32} Étoile : avantage / inconvénient ? :: + Un nœud défectueux n'affecte pas le reste du réseau.<br>− Si le nœud central (hub/switch) tombe, tout le réseau est inutilisable.
{n15@33} Étoile étendue ? :: Chaque nœud relié au nœud central est lui-même le centre d'une autre étoile (plusieurs étoiles reliées par un routeur central). C'est la topologie la plus utilisée.
{n15@34} Topologie hiérarchique : intérêt + 3 couches Cisco ? :: Rend le réseau modulable et facile à agrandir, simplifie l'administration et isole vite les problèmes.<br>Couches : cœur, distribution, accès.
{n16@35} Maillage complet : nombre de liaisons pour N terminaux ? :: N × (N − 1) / 2<br>ex. N = 10 → 45 liaisons.
{n16@36} Maillée : usage + inconvénient ? :: Pour les structures qui ne tolèrent aucune coupure (centrales nucléaires, routeurs du cœur d'Internet).<br>− Le nombre de liaisons explose quand N grandit.
```

## QCM du chapitre

```qcm
? {n14} Le schéma d'adressage IP apparaît sur la topologie…
- Physique
+ Logique
- En bus
- Hiérarchique
= Topologie logique : périphériques, ports et adressage IP. Topologie physique : emplacements et câbles.

? {n15} Dans une topologie en bus, si le câble commun se rompt…
- Seule la machine voisine est touchée
+ Tout le réseau tombe en panne
- Le jeton est régénéré
- Le second anneau prend le relais
= C'est la faiblesse principale du bus.

? {n15} Dans une topologie en étoile, si le nœud central tombe…
- Rien ne se passe
- Seul un hôte est isolé
+ Tout le réseau devient inutilisable
- Le trafic passe par le bus
= Inconvénient principal de l'étoile. En revanche, un nœud périphérique en panne n'affecte pas le reste.

? {n15} Le FDDI est…
- Un anneau simple
+ Un double anneau qui assure la tolérance aux pannes
- Une étoile étendue
- Un protocole WAN
= FDDI : paire d'anneaux ; le second permet la tolérance de panne du premier.

? {n15} Selon le cours, la topologie la plus couramment utilisée est…
- Bus
- Anneau
+ Étoile étendue
- Maillée
= Diapo 41 : l'étoile étendue est la plus couramment utilisée.

? {n15} Les 3 couches du modèle hiérarchique de Cisco sont…
- Physique, liaison, réseau
+ Cœur, distribution, accès
- Client, serveur, routeur
- Accès, transport, application
= Cœur, distribution, accès.

? {n15} Dans un anneau Token Ring, les données circulent…
- Dans les deux sens simultanément
+ Dans un sens unique, grâce à un jeton
- Par diffusion à tous les hôtes
- Via un hub central
= Chaque hôte passe les données à son voisin dans un sens unique ; un jeton circule.

? {n16} Combien de liaisons pour un maillage complet de 8 terminaux ?
- 56
+ 28
- 64
- 16
= 8 × 7 / 2 = 28. Le piège : 56 = N(N−1), sans diviser par 2.

? {n16} Un maillage complet compte 66 liaisons. Combien de terminaux ?
- 11
+ 12
- 33
- 13
= N(N−1)/2 = 66 donne N(N−1) = 132 = 12 × 11, donc N = 12.

? {n16} La topologie maillée est surtout utilisée…
- Dans les petits bureaux pour réduire les coûts
+ Là où aucune rupture de communication n'est tolérée
- Pour les réseaux personnels
- Uniquement en Wi-Fi
= Exemples du cours : centrales nucléaires, routeurs qui assurent la connexion Internet.
```
