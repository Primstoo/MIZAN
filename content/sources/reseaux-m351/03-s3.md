```html
<div class="def"><b>Les 5 éléments de base</b>Périphériques · Nœuds intermédiaires · Messages · Supports de transmission · Protocoles</div>
  <ul><li><b>Hôtes (end-users) :</b> envoient et reçoivent directement sur le réseau (PC, serveur, PDA). <b>Serveur</b> = hôte qui fournit des données ou des services (DHCP, DNS, Web). <b>Client</b> = hôte dont le logiciel interroge le serveur et affiche les informations.</li>
  <li><b>Périphériques partagés :</b> pas directement connectés au réseau, ils y accèdent à travers un hôte (imprimante, webcam).</li>
  <li><b>Nœuds intermédiaires :</b> transfèrent les messages d'une ligne d'entrée vers une ligne de sortie. <b>Commutateurs et concentrateurs</b> : hôtes d'un même segment. <b>Routeurs</b> : relient les segments entre eux.</li>
  <li><b>Messages :</b> convertis en bits (signaux numériques codés en binaire) avant l'envoi.</li>
  <li><b>Supports</b> (couche physique) : filaires (signal électrique sur câble métallique), optiques (lumière), sans fil / hertziens (ondes). <b>Critères de choix :</b> distance, environnement, quantité de données et débit, coût.</li></ul>
  <h3>Protocoles et normes</h3>
  <p>Une suite de protocoles décrit : le format du message ; le partage des chemins avec d'autres réseaux ; comment et quand transférer les messages d'erreur et système ; l'établissement et l'arrêt des sessions.</p>
  <div class="formula">Serveur Web ⇄ Navigateur
  HTTP      (Hypertext Transfer Protocol)
  TCP       (Transmission Control Protocol)
  IP        (Internet Protocol)
  Ethernet</div>
  <p><b>Norme :</b> processus ou protocole reconnu par l'industrie et ratifié par un organisme. <b>IEEE</b> : 802.3 (Ethernet), 802.11 (WLAN). <b>IETF</b> : normes Internet publiées en RFC (TCP, IP, HTTP, FTP).</p>
  <h3>Deux façons de se connecter à un autre périphérique (TD 2, ex. 1)</h3>
  <div class="formula">CLIENT-SERVEUR                         PAIR À PAIR (P2P)
 Client 1 ─┐                             Pair A ──── switch ──── Pair B
 Client 2 ─┼── Serveur                   (chaque machine est à la fois
 Client 3 ─┘                              client et serveur)</div>
  <ul>
    <li><b>Client-serveur</b> : un serveur dédié détient les ressources et fournit un service (Web, DNS, DHCP, messagerie) ; les clients envoient des requêtes. Administration et sécurité centralisées, mais le serveur est un point unique de panne.</li>
    <li><b>Pair à pair</b> : pas de serveur dédié, chaque hôte partage ses ressources avec les autres (partage de fichiers entre postes). Facile à installer, mais peu sécurisé et difficile à administrer quand le réseau grandit.</li>
  </ul>
  <h3>Domaines de collision et domaines de diffusion</h3>
  <div class="table-wrap"><table><thead><tr><th>Équipement</th><th>Couche</th><th>Domaines de collision</th><th>Domaines de diffusion</th></tr></thead><tbody><tr><td>Hub</td><td>1</td><td>un seul pour tous ses ports</td><td>ne sépare pas</td></tr><tr><td>Switch</td><td>2</td><td>un par port</td><td>ne sépare pas</td></tr><tr><td>Routeur</td><td>3</td><td>un par interface</td><td>un par interface</td></tr></tbody></table></div>
  <p><b>Domaine de collision</b> : zone où deux émissions simultanées se brouillent (support partagé). <b>Domaine de diffusion</b> : zone atteinte par une trame de diffusion (adresse FF:FF:FF:FF:FF:FF). Seul le routeur arrête la diffusion.</p>
  <div class="def"><b>Méthode pour compter sur un schéma</b>① Compte les câbles. ② <b>Collisions</b> : chaque câble est un domaine, sauf ceux qui touchent un même hub, qui se fondent en un seul (la liaison hub-switch appartient au domaine du hub). ③ <b>Diffusion</b> : les hubs et les switchs relient leurs câbles dans un même domaine ; chaque interface de routeur ouvre un domaine de plus (un PC branché directement sur un routeur forme le sien, et une liaison routeur-routeur aussi).</div>
```

## Flashcards

```cartes
{n7@11} Les 5 éléments de base d'un réseau ? :: Périphériques ; nœuds intermédiaires ; messages ; supports de transmission ; protocoles (règles de communication).
{n8@12} Hôte vs périphérique partagé ? :: Hôte (end-user) : envoie et reçoit directement sur le réseau (PC, serveur…).<br>Périphérique partagé : pas directement connecté, il accède au réseau à travers un hôte (imprimante, webcam…).
{n8@13} Serveur vs client ? :: Serveur : hôte qui fournit des données ou des services (DHCP, DNS, Web…).<br>Client : hôte avec un logiciel qui interroge le serveur et affiche les informations.
{n9@14} Rôle d'un nœud intermédiaire ? :: Transférer les messages d'une ligne d'entrée vers une ligne de sortie : routeur, commutateur (switch), concentrateur (hub).
{n9@15} Switch/hub vs routeur ? :: Switch et hub : connectent les hôtes au sein d'un MÊME segment.<br>Routeur : connecte les segments ENTRE EUX.
{n9@16} Messages : sous quelle forme circulent-ils ? :: Convertis en bits, c'est-à-dire en signaux numériques codés en binaire.
{n10@17} 3 catégories de supports de transmission ? :: Filaires (grandeur électrique sur câble métallique) ; optiques (lumière) ; sans fil / hertziens (ondes électromagnétiques). Ils se situent au niveau de la couche physique.
{n10@18} 4 critères de choix d'un support ? :: Distance ; environnement d'installation ; quantité de données et débit ; coût du support et de l'installation.
{n11@19} Pile de protocoles serveur web ↔ navigateur (haut → bas) ? :: HTTP → TCP → IP → Ethernet
{n11@20} Que fait une suite de protocoles ? (4 éléments) :: Le format du message ; la façon de partager les chemins vers d'autres réseaux ; comment et quand transférer les messages d'erreur et système ; l'établissement et l'arrêt des sessions.
{n11@21} Norme : définition ? :: Processus ou protocole reconnu par l'industrie et ratifié par un organisme de normalisation (IEEE, IETF).
{n11@22} IEEE vs IETF : exemples ? :: IEEE : 802.3 (Ethernet), 802.11 (WLAN).<br>IETF : normes Internet publiées en RFC (Request for Comments) : TCP, IP, HTTP, FTP.
{n8@129} Client-serveur ou pair à pair ? :: Client-serveur : un serveur dédié fournit un service à des clients. Pair à pair : chaque hôte est à la fois client et serveur, sans serveur central.
{n43@144} Domaines de collision : combien chez un hub, un switch, un routeur ? :: Hub : un seul pour tous les ports. Switch : un par port. Routeur : un par interface.
{n43@145} Domaines de diffusion : qui les sépare ? :: Seul le routeur (un domaine par interface). Hubs et switchs laissent passer la diffusion.
{n43@146} À quel domaine de collision appartient une liaison switch–hub ? :: À celui du hub : le câble partage le support avec tous les ports du hub.
```
