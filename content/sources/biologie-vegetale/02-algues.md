## Avant de commencer

Il faut savoir que la chlorophylle a est présente chez tous les organismes photosynthétiques oxygéniques.

```exercice Vérifie ton prérequis
? Une algue rouge contient-elle de la chlorophylle a ?
= Oui : toutes les algues ont la chlorophylle a. Ce sont les pigments accessoires qui changent.
```

## Comment aborder ce chapitre

> [!astuce] **Pense « couleur = pigments = groupe ».** Verte (chlorophylles a et b), brune (fucoxanthine), rouge (phycoérythrine).

> [!piege] Dire que les grandes algues ont des racines ou des vaisseaux. Même les laminaires géantes n'ont **ni racines ni vaisseaux** : elles se fixent par des **crampons** (haptères).

À la fin, tu sais classer une algue par ses pigments, ses réserves et son type de thalle.

## Idée 1 · Les trois grands groupes

```grille Comparaison
#cols: Groupe, Pigments accessoires, Réserve, Exemple
*Chlorophycophytes (vertes), chlorophylle b, amidon (dans le plaste), Ulva, Chlamydomonas
*Chromophycophytes (brunes…), chlorophylle c, fucoxanthine, laminarine, mannitol, Fucus, Laminaria
*Rhodophycophytes (rouges), phycoérythrine (phycobilisomes), amidon floridéen (hors du plaste), Porphyra
```

> [!retenir] Chez les algues rouges, les thylakoïdes sont isolés (non groupés), couverts de phycobilisomes.

## Idée 2 · Les types de thalles

```etapes Du plus simple au plus complexe
1. Unicellulaire (Chlamydomonas) ; colonies et cénobes (Volvox, nombre fixe de cellules).
2. Filamenteux (némathothalle) : simple ou ramifié.
3. Siphoné : une grande cellule multinucléée.
4. Tissus différenciés (cladomes, thalles foliacés) : laminaires.
```

## Idée 3 · La reproduction

- **Asexuée** : spores (zoospores flagellées ou aplanospores), fragmentation.
- **Sexuée** : isogamie (gamètes semblables), hétérogamie, oogamie (gros gamète femelle immobile). La **cystogamie** (fusion du contenu de deux cellules) existe chez des algues filamenteuses comme Spirogyra.

## S'exercer

```exercice Application
? Vrai ou faux : « les algues marines géantes sont parfois vasculaires ».
= Faux : aucune algue n'a de vrais vaisseaux.

? Vrai ou faux : « les algues benthiques se fixent par des racines adventives ».
= Faux : elles se fixent par des crampons (haptères) ou un disque.
```

## Flashcards

```cartes
Algues vertes :: Chlorophylles a + b, réserve en amidon.
Algues brunes :: Fucoxanthine, réserve en laminarine.
Algues rouges :: Phycoérythrine, amidon floridéen.
Cénobe :: Colonie au nombre de cellules fixé dès sa formation.
```

## QCM du chapitre

```qcm
? La chlorophylle a est présente :
+ chez toutes les algues
- uniquement chez les algues vertes
- chez les champignons
= Pigment de base.

? La chlorophylle b caractérise :
+ les algues vertes
- les algues rouges
- les algues brunes
= Comme les plantes terrestres.

? Les algues se fixent par :
+ des crampons
- des racines
- des rhizomes
= Haptères.

? La phycoérythrine colore :
+ les algues rouges
- les algues vertes
- les champignons
= Phycobilisomes.

? La réserve des algues brunes :
+ laminarine
- amidon
- glycogène
= Polysaccharide.

? Un némathothalle est :
+ filamenteux
- unicellulaire
- siphoné
= Filament.

? Une algue a des vaisseaux :
- souvent
+ jamais
- si elle est géante
= Thallophyte.

? L'oogamie implique :
+ un gamète femelle gros et immobile
- deux gamètes identiques
- l'absence de gamètes
= Œuf.

? Volvox est :
+ un cénobe
- un thalle siphoné
- un champignon
= Colonie.

? Spirogyra pratique :
+ la conjugaison (cystogamie)
- la pollinisation
- la germination de graines
= Fusion de deux cellules.
```
