## Avant de commencer

Il faut distinguer haploïde (n chromosomes) et diploïde (2n).

```exercice Vérifie ton prérequis
? La fécondation fait passer de… à… ?
= De n à 2n (deux gamètes haploïdes donnent un zygote diploïde). La méiose fait l'inverse.
```

## Comment aborder ce chapitre

> [!astuce] **Pense « deux grandes coupures ».** Thalle ou cormus (tige, feuilles, racines) ; puis spores ou graines.

> [!piege] Ranger les champignons parmi les plantes chlorophylliennes. Ils n'ont **pas de chlorophylle** : ils sont hétérotrophes.

À la fin, tu sais placer n'importe quel groupe dans l'arbre de classification.

## Idée 1 · L'arbre

```grille Les grands groupes
#cols: Groupe, Appareil végétatif, Vaisseaux, Dissémination
*Thallophytes (algues, champignons), thalle, non, spores
*Bryophytes (mousses, hépatiques), petit cormus sans vraies racines, non (hadrome et leptome), spores
*Cryptogames vasculaires (fougères, prêles, lycopodes), cormus, oui, spores
*Gymnospermes (conifères, Ginkgo, Gnétophytes), cormus, oui, graines nues
*Angiospermes (plantes à fleurs), cormus, oui, graines dans un fruit
```

> [!retenir] Embryophytes = toutes les plantes dont le zygote donne un embryo protégé : Bryophytes + Trachéophytes (Cryptogames vasculaires et Spermaphytes). Anthophytes = plantes à fleurs.

## S'exercer

```exercice Application
? Une plante a des vaisseaux, pas de fleurs et se dissémine par spores. Groupe ?
= Cryptogame vasculaire (une fougère par exemple).

? Chez une mousse, la plante verte feuillée est-elle n ou 2n ?
= n : c'est le gamétophyte. Le sporophyte (soie + capsule) est 2n et vit sur lui.
```

## Flashcards

```cartes
Thalle :: Appareil végétatif sans tige, feuilles ni racines vraies.
Cormus :: Appareil végétatif avec tige, feuilles, racines.
Spermaphytes :: Plantes à graines : Gymnospermes et Angiospermes.
Cycle haplodiplophasique :: Alternance d'un gamétophyte n et d'un sporophyte 2n.
```

## QCM du chapitre

```qcm
? Les champignons sont :
+ hétérotrophes
- chlorophylliens
- des plantes vasculaires
= Pas de chlorophylle.

? Les Anthophytes sont :
+ les plantes à fleurs
- les mousses
- les algues
= Angiospermes.

? Les Bryophytes possèdent :
+ un petit cormus sans vraies racines
- des vaisseaux lignifiés
- des graines
= Rhizoïdes.

? Les Gymnospermes ont des graines :
+ nues
- enfermées dans un fruit
- absentes
= Pas d'ovaire.

? Chez la fougère, la phase dominante est :
+ le sporophyte 2n
- le gamétophyte n
- le zygote
= Le prothalle est petit.

? Les plantes dites « à spores » :
+ Thallophytes, Bryophytes, Cryptogames vasculaires
- Gymnospermes
- Angiospermes
= Cryptogames.

? Un cycle diplophasique :
+ n'a que les gamètes haploïdes
- n'a que le zygote diploïde
- alterne deux générations
= Fucus, et les animaux.

? La méiose fait passer :
+ de 2n à n
- de n à 2n
- de n à n
= Réduction chromatique.

? Les Trachéophytes possèdent :
+ des vaisseaux conducteurs
- un thalle
- uniquement des rhizoïdes
= Trachéides, vaisseaux.

? Une algue est :
+ un thallophyte chlorophyllien
- un embryophyte
- un champignon
= Autotrophe.
```
