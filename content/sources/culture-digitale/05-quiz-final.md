Ce quiz mélange les 4 séquences, comme le quiz officiel (QCM et Vrai/Faux). Vise **16/20** avant l'examen.

```etapes Méthode le jour du quiz
Lis toute la question :: repère le mot piège (« toujours », « premier », « sécurisé »)
Élimine :: barre les réponses d'une autre époque ou d'une autre séquence
Vrai/Faux :: une seule erreur dans la phrase la rend fausse
Dates :: raccroche-les aux repères 1971, 1991, 1995
```

## Quiz (20 questions)

```qcm

- Vrai
+ Faux
= La RAM est volatile.
```
