## Avant de commencer

Il faut reconnaître un α-cétoacide (C=O à la place du NH₂) et un acide aminé.

```exercice Vérifie ton prérequis
? Quel acide aminé correspond au pyruvate ?
= L'alanine.
```

## Comment aborder ce chapitre

> [!astuce] **Pense « on échange le NH₂ ».** La transamination transfère le groupement aminé d'un acide aminé (souvent le glutamate) à un α-cétoacide.

> [!piege] Croire que l'ammoniac est éliminé tel quel chez l'humain. Il est toxique : le foie le convertit en **urée**.

À la fin, tu sais écrire une transamination et la réaction de la glutamate déshydrogénase.

## Idée 1 · Fixer l'ammoniac

Glutamate déshydrogénase : α-cétoglutarate + NH₄⁺ + NAD(P)H ⇄ glutamate + NAD(P)⁺ + H₂O. Réversible ; de fortes concentrations de NADPH et d'α-cétoglutarate poussent vers l'assimilation de l'ammoniac.

## Idée 2 · La transamination

```grille Familles d'acides aminés non indispensables (TD)
#cols: α-cétoacide, Acides aminés formés
*Pyruvate, alanine
*Oxaloacétate, aspartate, asparagine
*α-cétoglutarate, glutamate, glutamine, proline, arginine
*3-hydroxypyruvate, sérine
```

**Exemple.** Glutamate + pyruvate ⇄ α-cétoglutarate + alanine (alanine aminotransférase, coenzyme : phosphate de pyridoxal).

## Idée 3 · Dégradation et cycle de l'urée

```etapes Devenir d'un acide aminé dégradé
1. Transamination : le NH₂ passe sur l'α-cétoglutarate (glutamate).
2. Désamination oxydative du glutamate : NH₄⁺ libéré.
3. Cycle de l'urée (foie) : NH₄⁺ + CO₂ → urée, éliminée par les reins.
4. Le squelette carboné rejoint Krebs ou la néoglucogenèse.
```

## S'exercer

```exercice TD
? Écris la transamination qui forme l'aspartate.
= Glutamate + oxaloacétate ⇄ α-cétoglutarate + aspartate.

? L'arginine est-elle indispensable ?
= Seulement pour les nouveau-nés et les enfants, selon le TD.
```

## Flashcards

```cartes
Transamination :: Transfert du NH₂ d'un acide aminé vers un α-cétoacide.
Glutamate déshydrogénase :: α-cétoglutarate + NH₄⁺ ⇄ glutamate, réversible.
Cycle de l'urée :: Dans le foie, élimine l'azote sous forme d'urée.
Coenzyme des aminotransférases :: Phosphate de pyridoxal (vitamine B6).
```
