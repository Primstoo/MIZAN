  <h2>Exercice 1 · La figure géométrique <span class="src">diapos 88–89</span></h2>
  <div class="enonce">
    <p>Une figure contient : un triangle T1 qui contient un carré C1 (contenant un cercle plein R3), un cercle R1, et un triangle plein T2 (contenant un carré C2 et un cercle R2).</p>

  <h2>Exercice 2 · Le guichet automatique (GAB) <span class="src">diapos 179–180</span></h2>
  <div class="enonce">
    <p>Le client introduit sa carte dont la validité est immédiatement vérifiée. Il est ensuite invité à saisir le code de la carte. Après trois tentatives infructueuses, la carte est avalée. Sinon, le client peut indiquer le montant qu’il désire retirer ; le solde de son compte est alors consulté pour s’assurer que le retrait est possible. En cas de solde insuffisant, le client en est informé et peut alors saisir un montant inférieur. Si le solde est suffisant, le distributeur restitue la carte et délivre alors les billets accompagnés d’un reçu.</p>
    <p><b>Décrire le fonctionnement de ce GAB par un diagramme d’activités.</b></p>
  </div>
  <details class="corr"><summary>Voir la correction <span class="hint">essaie d’abord 20 minutes</span></summary><div class="in">
    <h3>Raisonnement</h3>
    <ol class="steps">
      <li>Deux responsables : le <b>Client</b> et le <b>Distributeur</b>, donc deux couloirs.</li>
      <li>« dont la validité est immédiatement vérifiée » : action puis décision <code>[valide]</code> / <code>[invalide]</code>.</li>
      <li>« Après trois tentatives » : une boucle qui revient avant « Demander le code », avec un compteur. On place une <b>fusion</b> avant « Demander le code » pour accueillir le retour.</li>
      <li>« peut alors saisir un montant inférieur » : deuxième boucle, retour vers une fusion avant « Demander le montant ».</li>
      <li>« restitue la carte et délivre <b>alors</b> les billets accompagnés d’un reçu » : la carte d’abord, puis billets et reçu en parallèle (fork / join).</li>
    </ol>
