Le devoir 2 du module, puis les calculs-clés des fiches de révision qui ne sont pas déjà dans les chapitres.

## Devoir 2

```exercice Devoir 2
? Ex. 1 : pH de NaHCO₃ 0,05 M (pKa1 = 6,30 ; pKa2 = 10,33).
= HCO₃⁻ est un ampholyte : pH = ½(6,30 + 10,33) ≈ **8,32**.
reponse: 8.32

? Ex. 2 : Ks de Cu(OH)₂, solution saturée à pH 7,4.
= [OH⁻] = 10⁻⁶·⁶ ; [Cu²⁺] = [OH⁻]/2 ; Ks ≈ **7,9·10⁻²¹**.

? Ex. 3 : pile Cd | Cd²⁺ (0,20 M) || Ag⁺ (0,20 M) | Ag. Potentiels et fem.
= E(Cd) = −0,40 + 0,03 log 0,2 ≈ **−0,42 V** ; E(Ag) = 0,80 + 0,06 log 0,2 ≈ **0,76 V** ; fem ≈ **1,18 V**. Cathode : argent. Réaction : $2Ag^+ + Cd \to 2Ag + Cd^{2+}$.
reponse: 1.18

? Ex. 3 : constante d'équilibre.
= log K = 2 × (0,80 + 0,40) / 0,06 = 40 : **K = 10⁴⁰**.
reponse: 40
```

## Exercices de révision (avril 2021)

```exercice Révision
? Ex. 1 : acide acétique 0,1 M, Ka = 2·10⁻⁵. pH et α.
= pH ≈ **2,85** ; α ≈ **1,4 %**.
reponse: 2.85

? Ex. 2a : volume de HCl à pH 1,7 à ajouter à 750 cm³ à pH 2,5 pour obtenir pH 2,15.
= Bilan de H₃O⁺ : $750\times10^{-2{,}5} + V\times10^{-1{,}7} = (750 + V)\times10^{-2{,}15}$, d'où **V ≈ 228 cm³**.
reponse: 228

? Ex. 2b, c : chlorure dans 250 cm³ de C, puis pH de D (5 cm³ de C + 495 cm³ d'eau).
= [Cl⁻] = [H₃O⁺] = 10⁻²·¹⁵ M : 250 cm³ contiennent ≈ **62,8 mg** de Cl⁻. Dilution par 100 : **pH = 4,15**.
reponse: 4.15

? Ex. 11b : équilibrer $ClO_4^- + I^- \to Cl^- + HIO$ en milieu acide.
= $ClO_4^- + 8H^+ + 8e^- \to Cl^- + 4H_2O$ et $I^- + H_2O \to HIO + H^+ + 2e^-$ (×4). Bilan : $ClO_4^- + 4I^- + 4H^+ \to Cl^- + 4HIO$.
```
